# 1.3.175

1.3.174 실제 PC 테스트에서 나온 쇼핑커넥트 실패를 고쳤습니다. 여행커넥트는 바뀌지 않습니다.

- AI 연출 사진 한 장 때문에 글 전체가 "확인 필요"로 멈추지 않습니다. 생성 요청의 접수 여부를 확인하지 못했거나, 검수가 미확정으로 보류됐거나, 최종 검수가 연출 사진을 거절하면 그 사진만 빼고 판매자 실사진으로 구성해 한 번 더 진행합니다. 새 이미지를 만들거나 요청을 다시 보내지 않습니다.
- 대표 이미지나 판매자 원본 사진의 문제, 로그인 만료, 취소, 전송 실패는 이전처럼 멈추고 알립니다.
- 살균기 썸네일에 청소기용 문구("흡입력 체크")가 들어가던 문제를 고쳤습니다. 청소기 문구는 청소기·흡입력 표기가 있는 상품에만 씁니다.
- macOS 설치 파일 빌드가 검사 단계에서 멈추던 문제를 고쳤습니다(임시 폴더 경로).

이전 검사 수준으로 되돌리려면 `.env`에 `SHOPPING_GATE_PROFILE=strict`를 설정합니다.

이미 "확인 필요"로 멈춘 소재에 이 수정이 그대로 적용되는지는 실제 PC에서 확인이 필요합니다.
