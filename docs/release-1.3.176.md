# 1.3.176

1.3.175 실제 PC 테스트에서 최종 이미지 검수가 글을 막던 문제를 고쳤습니다. 여행커넥트는 바뀌지 않습니다.

- 판매자 원본 사진은 다른 상품으로 판정된 경우에만 발행을 막습니다. 검수 응답이 형식 오류로 판정을 내지 못했거나, 본문 문장이 사진 모습을 다르게 묘사한 경우는 권고로 남기고 진행합니다.
- 생성한 연출 사진은 이전처럼 엄격하게 봅니다. 지적이 있으면 그 사진만 빼고 판매자 실사진으로 진행합니다(1.3.175).
- 썸네일 문구가 상품과 맞지 않으면 계속 막고, 대표 이미지만 다시 만듭니다.
- 파일 손상·변경·누락은 계속 막습니다.

이전 검사 수준으로 되돌리려면 `.env`에 `SHOPPING_GATE_PROFILE=strict`를 설정합니다.
