# v1.3.91

- Electron 시작 코드와 패키지 메타데이터를 단일 `app.asar` 아카이브 안에 묶어, 새 PC에서 개별 `.cjs` 시작 파일이 누락·격리되는 오류를 막습니다.
- Next.js, Prisma, 자동화 스크립트처럼 실제 파일 경로가 필요한 런타임은 `app.asar.unpacked`로 분리해 기존 자동화 동작을 유지합니다.
- 패키징 단계에서 ASAR 내부 메인 엔트리와 소스의 바이트 일치, 필수 unpacked 런타임 파일을 함께 검증합니다.

앱 시작 전에 `Cannot find module` 오류가 발생하는 PC는 자동 업데이트가 작동하지 않으므로 이 버전의 설치 파일을 직접 실행해야 합니다.
