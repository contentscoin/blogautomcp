# 쇼핑 글·상품 참조 이미지 생성 흐름

2026-10-08 사용자 지침: 본문은 자연스러운 사진만 사용한다. 상품 원본에 설명용 프레임을 씌우거나 에디토리얼 정보 카드로 대체하지 않는다.

## 작성·배치 기본값

`shopping-post-strategy/v2`의 글 기본값은 5~8절(권장 6절), 본문 1,200~2,800자다. 판매자 설명, 증빙이 있는 체험, 미확인 사항을 구분한다. 없는 구매·사용 경험을 만들지 않는다. 제휴 고지는 본문 맨 위에 한 번 놓는다.

기본 이미지 구성은 대표 썸네일 1장과 본문 사진 4장이다. 본문 첫 파트 앞에는 선택 모델·색상·옵션에 맞는 판매페이지 원본 1장을 놓고, 중간과 마지막 파트에 서로 다른 AI 연출 사진 3장을 분산한다. 각 파일에는 한 장면만 담는다. 부족한 컷을 반복 원본·상세컷 콜라주·정보 카드로 채우거나 완료 기준을 낮추지 않는다.

사양·가격·치수·주의사항은 본문 텍스트로 설명한다. 본문 이미지 안에는 제목, 설명문, 라벨, 화살표, 패널, 장식 프레임, 삽입사진, 분할 화면, 콜라주를 넣지 않는다. 실제 상품 표면에 원래 인쇄된 로고·문구는 유지한다. 원본에는 “판매페이지 원본 상품 사진”, 연출 사진에는 “상품 원본을 참조한 AI 연출 이미지” 캡션을 이미지 바깥에 표시한다. 연출 사진을 실사용·기능·효과의 증거로 제시하지 않는다.

## 상품 참조 연출사진

| 단계 | 처리 |
|---|---|
| 원본 선택 | 상품 정체성·옵션·형태를 확인할 수 있는 온전한 원본을 검토한다. 의류는 자연스러운 착용 자세와 주름을 허용하되, 가려지거나 왜곡되어 디자인을 판단할 수 없는 사진은 제외한다. |
| 참조 전달 | 실제 원본 파일을 생성 도구에 첨부한다. 참조했다고 프롬프트에 쓰는 것만으로 대체하지 않는다. 글자 있는 썸네일을 본문 연출의 참조로 사용하지 않는다. |
| 연출 | 기본 1:1 사진. 배경·포즈·거리·구도를 달리하면서 실제 색상·핏·길이·재질·봉제·주머니·잠금 구조를 유지한다. 보이지 않는 뒷면·안감·부품은 지어내지 않는다. |
| 대조 검수 | 원본과 결과를 함께 검사한다. 형태·비율·해당 부품·라벨·색상·표면과 자연스러움·추가 글자 없음·프레임 없음·단일 장면까지 11항목 모두 통과해야 한다. 누락·불확실·왜곡은 실패다. |
| 저장 | 생성 결과와 참조 원본의 SHA-256, 상품 스냅샷, shopping-reference-scene/v2 버전, 검수 결과를 저장한다. 참조 파일도 패키지에 보존한다. |
| 발행 전 | 현재 파일·상품·문단과 검수 기록의 연결을 확인하고 최종 픽셀을 다시 검사한다. 상품이 맞더라도 카드·프레임·합성 설명이 있으면 차단한다. |

연출 사진은 GENERATED_SCENE / reference-guided-scene / remoteGenerated=true로 기록한다. 생성 결과를 원본 또는 픽셀 잠금 합성으로 표시하지 않는다. 픽셀 단위 동일성을 보장하지 않는다.

## 썸네일

쇼핑 대표 썸네일은 1080×1080이다. 원본 사진을 크게 사용하고 핵심 제목을 최대 두 줄, 132–170px 굵은 글자로 표시한다. 강한 명도 대비와 핵심 단어 강조를 사용하며 작은 부제·불릿·배지·CTA·작은 상품 삽입사진·설명 패널은 사용하지 않는다. 120px·240px 축소 미리보기로 가독성을 확인한다. 긴 상세페이지·배너를 축소해 사진처럼 넣지 않는다.

전체 사진 위에 제목을 렌더링한 결과는 PHOTO_TEXT_THUMBNAIL / local-composite로 표시한다. 원본·결과 해시가 연결된 출처 기록을 보관한다. 큰 제목은 썸네일에만 허용한다. 별도 배경 생성 기능을 사용하는 경우에도 설명 카드로 만들지 않으며 실제 생성·합성 방식에 맞게 기록한다.

## 생성·수정 경로

- PC 자동 보강은 설정된 이미지 엔진을 사용하며 실패한 작업의 브라우저 대체는 기존 자동화 허용 설정을 따른다. 두 경로 모두 참조 파일 누락·변경을 검사한다.
- 수동 ChatGPT 경로는 post_get_draft의 imageSlots에서 referenceReady=true를 확인하고 referenceImages를 순서대로 실제 첨부한다. 생성 결과와 같은 슬롯의 referenceHashes를 post_apply_section_image에 보낸다. 참조가 준비되지 않으면 프롬프트를 제공하지 않는다.
- 해시는 준비된 참조와 결과를 연결한다. 외부 도구가 참조를 실제 사용했는지 해시만으로 증명하지 않으며 원본 대조 검수를 별도로 수행한다.
- 전송 한도를 넘으면 참조 없는 생성으로 진행하지 않는다. 여행의 기존 이미지 경로는 쇼핑 정책 변경 대상에서 제외한다.
- 이전 쇼핑 계획은 읽기만 할 때 자동 변경하지 않는다. 전체 이미지 준비를 명시적으로 실행하면 이전 매니페스트를 백업하고 새 사진 배치로 전환한다. 기존 파일은 보존하며 본문·상품 링크·예약 정보는 바꾸지 않는다. 한 컷 변경 요청으로 전체 유료 생성을 시작하지 않는다.

## 실패·승인·재시도

적합한 원본이 없으면 PRODUCT_REFERENCE_REQUIRED / needs_reference, 참조 해시 변경은 PRODUCT_REFERENCE_CHANGED, 왜곡·카드 검수 실패는 REFERENCE_SCENE_FIDELITY_FAILED로 중단한다. 이전 정보 카드와 본문용 제목 합성은 IMAGE_FORMAT_OBSOLETE로 거절한다. 기존 카드가 검수 메타데이터를 가지고 있어도 승인·발행 예외를 주지 않는다.

전략·상품·슬롯·연출 지시·참조 해시로 작업을 식별한다. 미해결 제출이 있으면 새 요청을 중복 전송하지 않고 기존 결과를 복구한다. 동일 결과의 유효한 재시도는 alreadyApplied로 응답한다. 원본을 반복하거나 생성 실패를 원본 성공으로 숨기지 않는다.

이미지나 원고 변경 시 이전 승인을 해제한다. 발행 작업은 보강 과정에서 생긴 새 버전을 자동 채택하지 않는다. 현재 소재를 다시 검토·선택해야 한다. 최종 이미지 검수 정책도 final-publication-image-audit/v2-natural-photo로 바뀌므로 이전 정책의 통과 기록을 재사용하지 않는다.

## 검증 범위

npm run test:shopping-natural-photos로 배치, 명시적 전환·백업, 원본 대조 검수, 카드·프레임 거부, 발행 픽셀 판정, 썸네일 렌더링을 오프라인 검사한다. 실제 모델 생성, 개별 예약 글 수정, 네이버 발행은 별도 실행 증거가 필요하다. 코드 반영만으로 실행했다고 주장하지 않는다.
