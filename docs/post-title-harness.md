# 포스팅 제목 생성 기준

상품 정보에서 검색 표현과 독자의 선택 고민을 정리한 뒤, 서로 다른 제목 후보 세 개를 내부에서 비교해 하나를 출력한다. 후보나 평가 항목을 원고 JSON에 추가하지 않는다. 제목만으로 검색 순위나 클릭률 향상을 보장하지 않는다.

## 입력과 생성

- 상품명 앞의 행사·평점·효능 홍보 문구는 검색어와 상품 정체에서 제외한다. 브랜드·모델·실제 상품 종류는 보존한다.
- 검색 표현은 상품명·설명·특징·본문에서 추론한다. 실제 수집한 자동완성은 표현 참고로만 사용한다. 수집 결과가 없으면 추론과 관측을 섞지 않는다. 자동완성은 검색량이나 인기 순위 자료가 아니다.
- 본문이 답할 수 있는 질문, 선택 조건, 확인할 차이 중 하나를 제목의 읽을 이유로 삼는다. 없는 체험·효능·비교 우위·가격·사양은 제목에서도 만들지 않는다.
- 상품을 식별할 수 있는 자연스러운 문장을 우선한다. 25~35자와 앞쪽 키워드 배치는 권장사항이다. 글마다 ‘특징과 선택 기준’ 같은 후미를 복제하거나 단어를 나열하지 않는다.
- 사용자가 명시한 제목은 그대로 유지한다. 제목 수정을 요청하지 않은 소재 보완에서도 제목을 바꾸지 않는다.

## 적용 경로와 검증

공유 작성 계약은 PC 생성, MCP 문맥 제공·제출, 브라우저 복구, 소재 수정에 같은 제목 지침을 전달한다. Spec-first 생성·로컬 대안·수리도 같은 상품 기반 제목 기획을 사용한다. 생성 단계에서 본문과 제목을 맞추고, 제출 후에는 상품 혼입·없는 직접 체험·실질적인 과장·가까운 형제 제목 중복을 교정한다. 길이와 카테고리 키워드의 전체 문자열 불일치만으로 좋은 제목을 기계적으로 바꾸지 않는다.

과거 SEO 참고팩의 제목 후보는 현재 수요가 확인된 후보로 취급하지 않는다. 새 제목 하네스와 현재 상품 근거를 우선한다. 공통 상품명이 들어 있다는 이유만으로 다른 질문의 형제 글을 중복으로 처리하지 않는다.

## 기존 사례에 적용할 제목 방향

아래는 실제 저장 제목과 해당 상품·본문에 맞춰 작성한 개선 예시다. 저장된 소재를 일괄 변경하거나 실제 모델 결과·클릭 성과를 측정한 기록은 아니다.

| 기존 제목 | 개선 예시 |
| --- | --- |
| 4.93 추천 \| 상황별로 고르는 기준 | 한우 선물세트, 받는 사람 취향에 맞춰 고르는 법 |
| 토너 2주 잡티 개선 특징과 선택 기준 | 달바 비타 토닝 3종 세트, 내 루틴에 다 필요할까? |
| 드라이기 JMW 에어젯 울트라 PRO 사양과 선택 기준 | JMW 에어젯 울트라 PRO, 1700W만 보고 고르면 될까? |

클릭 성과는 적용 후 제목별 노출·클릭과 본문의 일치를 함께 살펴야 한다. 자동완성 결과를 성과 지표 대신 사용하지 않는다.
