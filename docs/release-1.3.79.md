# v1.3.79 — 발행 원고 품질검사 일치 및 자동 복구

- 승인 단계와 최종 발행 단계가 실제 렌더 문단을 같은 방식으로 검사하도록 통일했다.
- 구버전 검사 결과가 남은 승인 소재는 외부 발행 요청 전에 현재 기준으로 다시 검사한다.
- 재검사에서 원고 품질이 떨어지면 저장된 상품 근거와 이미지 구성을 유지하면서 실패 항목만 최대 3개 후보로 보강하고, 통과한 새 리비전만 발행한다.
- 문단 밖의 무관한 근거를 빌려 통과시키지 않으며, 기능·수치와 사용 장면의 이점 또는 제약을 같은 문단의 인접 문장으로 연결하는 기준을 유지한다.
- `2.4kg` 같은 소수점 수치가 문장 경계로 잘못 분리되어 근거 연결에서 빠지는 문제를 수정했다.
- 자동 복구가 실패하면 외부 발행을 시작하지 않고 원인을 그대로 남긴다. 응답이 불확실한 발행은 기존과 같이 자동 재시도하지 않는다.

## 검증

- 타입 검사와 변경 파일 lint 통과. 전체 lint의 기존 오류는 이번 변경 범위 밖이다.
- 소재 회귀 검사 16개 통과.
- 실제 렌더 문단 재검사, 구버전 검사 결과 차단, 소수점 수치 근거 연결, 발행 전 자동 복구와 새 리비전 제출을 회귀 검사로 확인했다.
- Next.js 프로덕션 빌드 통과.

실제 네이버 발행은 설치 후 사용자가 선택 소재를 다시 발행할 때 실행된다. 그 전에 현재 기준 재검사와 필요한 원고 보강이 완료되어야 한다.
