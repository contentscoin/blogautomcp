# 1.3.148 — 최종 사진 검수의 참조 귀속과 Windows 저장 안정성

최종 사진 검사에서 슬롯에 연결된 원본과 추가 갤러리의 역할을 구분합니다. 같은 상품의 반대 면이나 다른 색상 사진에 보이는 로고를 해당 사진의 누락으로 오인하지 않도록 실제 부품·면과 참조 인덱스의 대응 근거를 확인합니다. 실제 같은 면의 인쇄 누락, 읽히는 다른 브랜드, 다른 형상·확정 옵션, 식별 불확실성은 계속 차단합니다. 근거 연결이 잘못된 판정은 사진을 보존하고 검사를 보류하며, 승인이나 재생성 근거로 사용하지 않습니다.

지정 원본을 참조한 연출 사진은 원본에서 관찰되는 컷·봉제·목단·재질·색상·구조·선택 옵션과의 외형 충실성을 검사합니다. 원래 무표기인 상품의 사진만으로 시장 내 유일성이나 정품·정확한 SKU를 인증하라고 요구하지 않습니다. 상품명·출처·AI 고지만으로 승인하지 않으며, 실제 대응 특징이 충분히 보여야 합니다. 작은 표식이 실제 보이나 글자가 판독되지 않는 경우와 분명히 노출된 빈 인쇄면도 구분합니다. 원문이 사진으로 정품·사이즈·글자를 입증한다고 주장하면 그 주장에 필요한 근거는 계속 요구합니다.

Windows에서 완성된 임시 파일을 기존 원고 manifest로 교체하는 순간 일시적인 파일 점유가 발생하면 제한된 범위에서 교체만 재시도합니다. 기존 대상 파일을 삭제하거나 덮어쓰는 우회는 사용하지 않으며, 지속적인 권한 오류와 동시 변경은 실패로 남겨 원래 데이터를 보존합니다.

최종 검사에서 실제 식별 인쇄 오류가 확인된 현재 사진은 해당 본문·상품 원본·단일 완료 생성 요청과 결합된 서버 검증 증거를 통해서만 한 번의 후속 복구를 허용합니다. 완료·실제 배정·거절 근거를 확인하며, 경쟁 요청이 여러 개이거나 모호한 요청·진행 중인 요청이 있으면 그대로 보류합니다. 이전 생성 기록·예산과 다른 정상 사진을 유지하며, 새 결과도 원본 비교와 최종 검수를 통과해야 합니다.

기존 원고·정상 사진과 실패 기록을 유지하고 승인 전 최종 원고·사진 검사를 계속 수행합니다. 소재 준비와 발행은 별도 단계이며 이 수정이나 복구 작업은 발행을 요청하지 않습니다. 실제 네 소재의 최종 승인 준비 결과는 수정본의 실제 검증 결과로 별도 확인합니다.
