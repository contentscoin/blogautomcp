# v1.3.20

- 쇼핑/여행 전환 시 이전 옵션 요청을 즉시 무효화하여 종류와 URL 혼합을 방지합니다.
- 동기화는 종류별 설정 URL을 실제 CLI까지 전달하고, 반대 종류 URL은 실행 전에 거부합니다. 쿼리 문자열을 포함한 URL도 CLI에 보존합니다.
- 동기화 실패 시 실제 오류와 선택 종류를 표시합니다.
- 자연스러운 추천 대상/우선 조건 문장을 최종 결론으로 인식합니다. 품질 점수나 발행 기준은 낮추지 않습니다.
- MCP/데스크탑 섹션 이미지에 사진풍 지침을 강화하고, 상품 분리 실패 시 액자형 합성 대신 생성된 배경 사진을 보존합니다. 원본 상품은 재생성하지 않습니다.
- MCP 이미지 프롬프트에 주변 섹션 제목을 전달합니다.
- 중앙 MCP에 사용자 동의 기반 bug_report_create/bug_report_get 기능을 추가합니다. Telegram 봇은 새 관리자 비밀 설정이 필요하며, 미설정이면 중앙 접수만 저장합니다.

기존 원고/이미지는 삭제하거나 자동 발행하지 않습니다. 새로운 이미지 생성 품질과 네이버 실제 공개 발행 성공은 별도 실사용 검증 대상입니다.
