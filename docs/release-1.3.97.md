# v1.3.97 — 자연스러운 쇼핑 사진과 큰 제목 썸네일

쇼핑 본문에서 상품 사진을 설명 카드나 프레임에 넣던 경로를 제거했습니다. 실제 상품 원본을 참조해 자연스러운 단일 사진을 만들고, 생성·적용·승인·발행 검수에 동일한 기준을 적용합니다.

- 본문 기본 구성: 원본 1장과 서로 다른 AI 연출 사진 3장. 설명문·정보 패널·프레임·콜라주·반복 원본으로 수량을 채우지 않습니다.
- 상품 형태·옵션·색상·핏을 원본과 대조하고, 자연스러움·추가 글자 없음·프레임 없음·단일 장면까지 11개 항목을 확인합니다.
- 대표 썸네일은 1080×1080, 큰 상품 사진과 132–170px 제목 최대 두 줄로 만듭니다. 기존 작은 카드 썸네일의 자동 재사용을 막습니다.
- 이전 이미지 계획은 전체 이미지 준비에서 백업 후 전환합니다. 원문과 예약 정보는 유지하며, 개별 컷 수정으로 전체 생성이 시작되지 않습니다.
- 완료된 구버전 이미지 작업은 보존하고 새 전략으로 진행합니다. 제출 여부가 불명확한 요청은 중복 생성하지 않습니다.
- 정상 상품 원본을 잘못 거절하던 검증 분기를 수정했습니다.

검증: CI 단위 검사 26개, 자연사진 전용 검사 9개, 타입 검사 및 프로덕션 빌드 통과. 실제 유료 생성과 네이버 예약 글 변경은 이번 릴리스 검증에 포함하지 않습니다.
