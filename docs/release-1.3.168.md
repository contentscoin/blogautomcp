# 1.3.168

- 인쇄 검수 응답이 같은 표면을 ‘무인쇄’로 분류하면서 다른 구성원의 인쇄 좌표를 넣는 등 필드가 모순되면, 사진 결함과 구분해 응답 계약 오류로 기록합니다.
- 확실히 수신된 응답 계약 오류는 같은 입력으로 한 번만 복구합니다. 첫 응답과 해시·거절 이유를 보존하고, 실제 부적합 판정이나 전송 결과가 불명확한 요청은 반복하지 않습니다. 두 번째 응답도 유효하지 않으면 승인을 보류합니다.

원시 좌표·문구·판정 값을 수정하지 않으며 승인 전 최종 검수를 유지합니다. 기존 원고와 정상 이미지를 보존하고 초기화·예약·발행은 실행하지 않습니다.
