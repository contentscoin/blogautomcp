# v1.3.81 — 소재 미리작성 첫 통과율 개선

1.3.80 소재 10개 일괄 작성에서 나온 실패 세 가지의 원인을 고쳤다.

- **원고 구조 부족("구조화 흐름 1개")**
  - JSON 파서가 본문의 “ ” 따옴표를 먼저 `"`로 바꿔 올바른 JSON을 깨뜨렸다. 이제 원문을 먼저 파싱한다.
  - 출력 예시에 섹션이 1개만 있어 모델이 전체를 한 원소에 몰아 썼다. 예시를 2개로 바꾸고 "섹션마다 원소 하나"를 명시했다.
  - 원고 호출에 구조화 출력(JSON 스키마)을 적용했다.
  - 섹션이 객체로 오거나 한 문자열에 합쳐져 오면 내용 그대로 나눈다. 그래도 모자라면 같은 지시로 1회만 다시 받는다.
- **상품 고유 근거 미달로 보강 중단(QUALITY_REPAIR_EXHAUSTED)**
  - 품질검사가 세는 확인 사실 목록과 필요한 개수를 작성 프롬프트에 그대로 넣었다. 첫 원고에서 통과하도록 하기 위해서다.
  - 보강 지시에 "본문에 아직 없는 사실"과 "판단에 연결되지 않은 사실"을 이름으로 적어, 같은 실패를 반복하지 않게 했다.
- **이미지 재배치 중단(INVALID_REVIEW)**
  - 이미지 판정에 구조화 출력 스키마를 적용했다.
  - 판정 앞뒤의 설명 문장, 문자열로 온 index, 문자열로 온 true/false를 받아들인다. 빠진 안전 필드는 추정하지 않는다.
  - 형식이 깨진 판정만 1회 다시 묻는다.
  - 제안 이미지 하나의 판정이 깨져도 그 제안만 빼고 나머지 재배치는 계속한다.
