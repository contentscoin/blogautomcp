# 1.3.158

- 서로 다른 원본 글자 판독이 합의되지 않을 때, 같은 종류의 완전한 글자 영역이 다른 원본보다 4배 이상 크게 보이는 원본을 비교 입력으로 우선합니다. 후보의 철자를 선택 기준으로 쓰지 않으며, 실제 비교·OCR 검증을 생략하지 않습니다.
- 원본 사진에 정해진 제목을 합성한 썸네일은 실제 렌더러로 다시 계산한 파일 전체 바이트가 정확히 같은 경우에만 중복 글자 판독을 생략합니다. 현재 원본·출력 해시와 검증된 판매자 원본 연결, 별도 제품·본문·형식 검사는 유지합니다. 저장된 표식만으로 통과할 수 없고 새 프로세스에서는 다시 계산합니다. 이미지나 문구가 다르면 기존 검수로 돌아갑니다.
- 포장과 여러 제품이 함께 있는 원본에서는 후보와 대응하는 기기 앞면을 먼저 찾도록 위치 확인 지침을 구체화했습니다. 고정 단어 영역의 픽셀 좌표도 제공하며, 기존 정규화 좌표·공간 분리 검증은 유지합니다.
- 일반적인 소제목을 사진이 착용 구조를 입증한다는 주장으로 혼동하지 않도록 본문 대응 지침을 보강했습니다. 명시적인 사진 속 외형·수량·구성 주장은 계속 확인합니다.

검증: 사진 검수 회귀 14,616개, 타입·린트, 실제 현미경 썸네일의 전체 바이트 재현. 진단 재현 자체는 소재 승인 결과가 아닙니다. 배포 후 실제 MCP 보완 결과를 별도로 확인합니다.
