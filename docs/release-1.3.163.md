# 1.3.163

제품 확대 원본과 착용 원본의 시야 차이, 작은 인쇄의 관찰 한계를 실제 사진 결함과 구분하도록 최종 검수 경로를 보완했습니다.

- 원본 소속 검사가 서로 다른 시야 때문에 불확실한 경우 원문과 해시를 보존하고, 생성 사진과 확대 원본의 같은 부품·면·옵션을 직접 비교합니다. 기존 브랜드 역할 특례는 부여하지 않으며, 읽히는 차이는 독립 OCR까지 확인해야 결함으로 처리합니다.
- 전체 제품 형태·본문 주장·사진 형식 검사가 통과한 정상 사진에서 작은 인쇄의 위치 관계를 확정하지 못하면 인쇄 미검증 경고로 기록합니다. 글자 정확성·빈 인쇄면·재생성 권한을 부여하지 않습니다. 실제 모양·옵션 충돌과 노출된 빈 인쇄면, 읽히는 글자 차이는 이 경로로 통과시키지 않습니다.

기존 원고·정상 사진을 보존하며, 두 소재의 승인 준비 완료는 설치 후 MCP의 실제 최종 결과로 확인합니다. 초기화·발행은 수행하지 않습니다.
