# v1.3.88 — 최종 이미지 감사 거절 복구, 재검사 경합 재시도, 상세 이미지 드러내기

1.3.87에서는 원고와 이미지 보충이 통과했지만, 승인 직전의 최종 이미지 감사에서 막혔다.

- **최종 감사에서 이미지가 거절돼 실패(베이직북14·캠핑웨건·컬크림)**
  - 원인
    - 거절 뒤에는 원본 교체 1회와 재계획 1회를 시도한다. 그런데 재계획은 이미지 단계에서 이미 한 번 쓴 기록 키를 공유해서, 여기서는 실행되지 않았다.
    - 선택 섹션처럼 교체가 필요 없는 슬롯에 있는 거절 이미지는 제거 대상이 아니었다.
    - 거절 사례: 다른 모델의 비교 문구, 옵션이 섞인 카드, 홍보 패널이 함께 잘린 연출컷.
  - 수정
    - 교체 실패, 두 번째 거절, 거절 뒤 빈 슬롯이 없는 경우 모두 별도 기록 키(`replan-after-rejection`)로 재계획을 한 번 실행한다.
    - 이 재계획은 거절 이미지를 빼고, 3장 이상 남으면 해당 섹션의 사진 요구를 완화한 뒤 재승인한다.
    - 거절된 AI 연출컷 슬롯도 같은 방식으로 처리한다.
- **"상품 상태가 변경되었습니다"로 실패(베이직북14)**
  - 원인: 재검사가 상품 상태를 잡는 순간, 같은 상품에 대한 다른 요청과 겹쳤다.
  - 수정: 이 경합 오류가 나면 잠시 기다린 뒤 최대 3번 다시 시도한다.
- **상세 이미지 1장만 수집(삼탠바이미)**
  - 원인: 수집할 때 페이지를 스크롤하지 않았고, "상세정보 펼쳐보기"도 누르지 않았다. 그래서 지연 로딩되는 상세 이미지가 수집 대상에 없었다.
  - 수정: 수집 전에 펼침 버튼을 누르고 페이지를 끝까지 한 번 내린다(최대 약 8초). iframe 안의 이미지도 후보로 모은다.
