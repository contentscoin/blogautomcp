# v1.3.98 — 실패 소재 일괄 재작성 및 검증

소재 작성에 실패한 글을 다시 처리할 때 개별 원고를 하나씩 열어 복구하던 작업을 한 번에 시작할 수 있습니다. PC 소재 보관함과 Sites 대시보드의 `실패 소재 전체 재작성·검증` 버튼, 플러그인의 `materials_rewrite_failed` 명령이 같은 작업 흐름을 사용합니다.

- 현재 실패한 작성 소재만 선정하고, 이미 준비 완료·게시·예약된 글 및 실행 중이거나 결과가 불명확한 작업을 제외합니다.
- 텍스트 재작성 전 기존 패키지를 백업하고 최신 상품 근거를 수집합니다. 원고가 통과하고 이미지만 부족한 소재는 이미지 복구와 검증을 진행합니다.
- 원고 품질, 자연사진 구성, 이미지 검증 및 승인 기준을 통과한 소재만 발행 준비 완료로 저장합니다. 실패하거나 중단된 항목은 원인과 함께 표시합니다.
- 같은 요청을 다시 보내도 같은 작업을 반환하며, 응답 유실과 중복 클릭으로 다른 작업을 시작하지 않습니다.
- 실제 발행은 소재를 선택한 뒤 기존 발행 절차로 진행합니다.

새 플러그인 명령과 Sites 버튼은 PC 앱 1.3.98 이상에서 사용할 수 있습니다.
