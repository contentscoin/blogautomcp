# Naver BrandConnect Category Style Guide v2

작성일: 2026-07-02
기반 자료: `docs/naver-blog-drafts/2026-07-02-*.md`

## Universal Structure

모든 카테고리는 아래 순서를 유지한다.

1. 구매 전 기준 문제 제기
2. 제품명/검색 키워드 해체
3. 사용 장면 또는 사용 과정
4. 장점
5. 아쉬운 점/주의점
6. 추천 대상
7. 구매 전 체크리스트
8. 마무리

## Category Rules

### 반려/펫

대표 초안: `2026-07-02-penobis-oralvet-baby-pet.md`

- 핵심 문체: 보호자 관점, 친근체, 정보형
- 사진: 제품 패키지, 반려동물 반응, 사용 준비, 사용 장면, 보관
- 제목 키워드: 제품명, 강아지/고양이, 치약/구강케어, 추천, 사용 전 체크
- 신뢰 장치: 아이마다 반응이 다를 수 있음을 명시
- 금지: 치료, 질환 개선, 구취 해결 보장, 치석 제거 보장

### 디지털/IT

대표 초안: `2026-07-02-lg-gram-digital-it.md`

- 핵심 문체: 목적별 비교형, 사무/학업 사용 장면 중심
- 사진: 제품 오픈 컷, 키보드, 포트, 충전기, 카페/강의실/사무실 사용 장면
- 제목 키워드: 브랜드/모델명, 노트북, 대학생, 사무용, 후기, 구매 전 체크
- 신뢰 장치: 세부 사양과 무게는 상세페이지 최신 표기 확인
- 금지: 성능, 배터리, 무게, 속도 수치 임의 단정

### 뷰티/헤어/바디

대표 초안: `2026-07-02-breezeon-hair-dryer-beauty-body.md`

- 핵심 문체: 체험형, 비교형, 사용 루틴 중심
- 사진: 본체, 구성품, 조작부, 노즐, 손에 든 크기감, 사용 장면
- 제목 키워드: 브랜드/제품명, BLDC, 헤어드라이어, 후기, 구매 전 체크
- 신뢰 장치: 풍량, 소음, 무게, 건조 시간은 환경별 체감 차이 명시
- 금지: 즉시 건조, 무조건 빠름, 초강풍 보장, 무소음 단정

### 식품/건강식품

대표 초안: `2026-07-02-drby-probiotic-food-supplement.md`

- 핵심 문체: 보호자 판단형, 성분 확인형, 주의점 우선
- 사진: 패키지, 개별 포장, 성분표, 급여량, 사료와 함께 둔 컷, 급여 루틴
- 제목 키워드: 제품명, 강아지 유산균, 프로바이오틱스, 장건강 영양제, 후기
- 신뢰 장치: 성분, 급여량, 알레르기, 수의사 상담 가능성
- 금지: 치료, 개선 보장, 장건강 해결, 즉시 효과

### 가전/청소/주방가전

대표 초안: `2026-07-02-hanil-bldc-fan-home-appliance.md`

- 핵심 문체: 사용 공간별 비교형, 기능 확인형
- 사진: 제품 전체, 구성품, 조작부, 리모컨, 설치/조립, 실제 공간 사용 장면
- 제목 키워드: 제품명, 기능 키워드, 후기, 추천, 구매 전 체크
- 신뢰 장치: 소음, 성능, 조립, AS, 보관 기준을 분리
- 금지: 완전 무소음, 무조건 조용, 성능 수치 임의 추가

### 패션/잡화/의류

대표 초안: `2026-07-02-orokko-pure-shorts-fashion-goods.md`

- 핵심 문체: 착용 후기형, 핏/소재/구성 비교형
- 사진: 제품 단독, 소재, 허리/주머니, 정면/측면/후면 착용샷, 코디 컷
- 제목 키워드: 브랜드/제품명, 기장/소재, 반바지/바지, 후기, 구매 전 체크
- 신뢰 장치: 체형과 취향에 따라 핏 체감 차이 명시
- 금지: 누구나 잘 맞음, 핏 보장, 최저가 보장, 사이즈 단정

### 생활/건강/욕실

대표 초안: `2026-07-02-decle-oneshotclean-living-health.md`

- 핵심 문체: 사용 과정형, 전후 비교형, 관리 주의형
- 사진: 제품, 부품, 사용 전 상태, 사용 과정, 사용 후 상태, 오염수/세척/보관
- 제목 키워드: 제품명, 습식청소기/방향제/디퓨저 등 카테고리, 후기, 구매 전 체크
- 신뢰 장치: 소재, 오염도, 사용법, 관리 난이도에 따른 차이 명시
- 금지: 완벽 제거, 즉시 효과, 냄새 완전 제거, 새것처럼 보장

### 스포츠/레저/골프

대표 초안: `2026-07-02-strong-golf-umbrella-sports-leisure.md`

- 핵심 문체: 야외 사용 장면형, 크기/보관/내구 비교형
- 사진: 전체 펼친 컷, 접은 길이, 손잡이, 소재/살대, 골프백/차량 보관, 야외 사용
- 제목 키워드: 제품명, 골프, 장우산, 자동, 자외선차단, 후기, 구매 전 체크
- 신뢰 장치: 강풍, 차광, 방수는 상세페이지 표기와 사용 환경 확인
- 금지: 절대 뒤집히지 않음, 자외선 완벽 차단, 할인율 보장

## Thumbnail Rule By Category

| Category | Thumbnail Core |
| --- | --- |
| 반려/펫 | 제품 + 반려동물 + 사용 전 체크 |
| 디지털/IT | 제품 오픈 컷 + 책상/카페/강의실 맥락 |
| 뷰티/헤어/바디 | 본체 + 손에 든 크기감 + 사용 장면 |
| 식품/건강식품 | 패키지 + 급여 맥락 + 보장 문구 없음 |
| 가전/청소/주방가전 | 제품 전체 + 조작부/리모컨 + 실제 공간 |
| 패션/잡화/의류 | 착용샷 + 제품 구성 + 기장/소재 키워드 |
| 생활/건강/욕실 | 사용 전후 또는 사용 과정 + 제품 |
| 스포츠/레저/골프 | 제품 전체 크기 + 야외/골프백 맥락 |
