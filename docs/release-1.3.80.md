# v1.3.80 — 상품 유형 템플릿, 한 상품 여러 포스팅, photoreal·Codex 이미지 생성

- 원고 모델을 gpt-6-luna(low)로 고정했다.
- 검수 기준을 완화했다: 통과 점수 62, 필수 카테고리는 상품 근거 하나, 재작성은 1회. 안전 차단은 그대로다.
- 쇼핑 8종·여행 4종 상품 유형 템플릿을 추가했다. 섹션마다 이미지 출처(상세 원본·원본 크롭·연출컷)를 정하고, 여행은 꿀팁 컨셉으로 쓴다.
- 한 상품으로 전체 리뷰와 주제 글 여러 편을 쓸 수 있다("포스팅 주제" 패널). 근거가 없는 주제는 숨기고, 형제 글과 겹치는 문장은 1회 재작성하며, 예약 간격은 최소 2일이다.
- 상세페이지 이미지 비전 판독, 네이버 자동완성 검색 수요, SEO 제목 후보를 추가했다.
- 직접 체험 메모를 상품 단위로 저장한다. 메모가 있으면 메모 범위 안에서만 1인칭 체험형으로 쓰고, 없으면 정보형으로 쓴다.
- photoreal 스킬을 내재화했다. 섹션 이미지는 API 키 없이 Codex 로그인(gpt-image-2)으로 생성하고, 생성 후 점검표로 1회 확인해 걸린 항목만 보강한다. Codex가 실패한 이미지만 ChatGPT 웹으로 대체한다(`BRAND_POST_IMAGE_ENGINE=browser`로 예전 방식 사용 가능).

## 검증

- 타입 검사, CI lint, CI 단위 검사, 소재 회귀 검사 16개, Next.js 프로덕션 빌드 통과.
- 신규 회귀 검사: 템플릿, 포스팅 각도, 상세 판독, 제목 플래너, 체험 메모, photoreal 원본 일치, Codex 이미지 전송(목).

실제 Codex 이미지 생성은 Codex 로그인이 된 PC에서 처음 실행된다. 로그인이 없으면 ChatGPT 웹 경로로 대체된다.
