# 1.3.159

확대 판매자 사진과 착용 사진을 비교할 때 같은 물리 부위를 찾도록 독립 관찰의 위치 좌표를 전달합니다. 좌표는 글자 정답이나 제품 일치 판정이 아니며, 원래 관찰·파일 해시·요청에 묶여 재검증됩니다. 변경된 좌표를 다시 해시한 결과도 수용하지 않습니다.

포장에만 글자가 있고 기기 앞면은 비어 있는 사진의 검수 설명을 명확히 했습니다. 두 사진 모두 인쇄가 없는 동일 면과, 원본에는 인쇄가 있지만 후보에서 사라진 경우를 구분합니다. 실제 인쇄 오류, 구조 불일치와 미확정 관찰은 자동 승인하지 않습니다.

원고·이미지를 삭제하거나 다시 생성하는 변경은 없습니다. 기존 검수 결과를 현재 정책에서 다시 확인하는 정상 보완 경로를 사용합니다. 초기화·발행은 실행하지 않습니다. 실제 두 소재의 승인 준비 여부는 배포 후 작업 결과로 별도 확인해야 합니다.
