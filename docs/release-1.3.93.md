# v1.3.93 — Product 9Canvas 기반 소재 생성 안정화

- 상품명, 판매자 근거, 카테고리, 옵션 상태, 사용 맥락을 `Product 9Canvas`로 먼저 정리하고 원고·썸네일·본문 이미지·최종 감사를 하나의 상품 이해 계약으로 연결합니다.
- `캠핑` 같은 사용 맥락이 가습기를 보냉용품으로 바꾸지 않도록 강한 상품 명사를 우선하며, 혼합 옵션은 단일 구성으로 단정하거나 한 이미지에 섞지 않습니다.
- 웨어러블·휴대형·탁상형·바닥형·패키지형의 실제 크기 차이를 이미지 합성 배치에 반영합니다.
- 저장된 예전 썸네일 문구가 현재 상품 이해와 충돌하면 재사용하지 않고 새 계약으로 다시 만듭니다.
- 검증 실패를 정보 수집, 상품 이해, 원고, 이미지 계획, 이미지 원본, 합성 단계로 분류하고 원인을 제거할 수 있는 단계부터 제한적으로 복구합니다. 최종 품질 기준은 유지합니다.
