# v1.3.83 — 검증 이미지 부족·오래된 원고 보강 실패 수정

1.3.82 소재 작성에서 남은 실패 6건(검증 이미지 부족 5건, 원고 보강 실패 1건)의 원인을 고쳤다.

- **새 재배치 로직이 실행되지 않음**
  - 이미지 복구 기록은 "같은 원고·같은 근거면 다시 시도하지 않음"으로 동작한다. 그래서 이전 버전에서 한 번 실패한 소재는 1.3.82에서 새로 넣은 재배치 단계를 아예 거치지 않았다.
  - 복구 기록 키에 복구 로직 버전을 넣었다. 로직이 바뀌면 한 번 새로 시도한다.
- **검증 이미지 부족(REPLAN_INSUFFICIENT_VERIFIED_ALTERNATIVES)**
  - 판매자 원본으로도, AI 연출 대체로도 기능 근거 사진을 채우지 못한 경우를 처리했다.
  - 글 전체 이미지가 기준(쇼핑 최소 5장, 대표 이미지 포함) 이상이면 그 기능 섹션은 증거 사진 없이 둔다. 글과 이미지 의도는 바꾸지 않는다.
  - 전체 이미지도 부족하면 여전히 멈추고, 부족한 장수와 생성 실패 이유를 메시지에 남긴다.
- **AI 연출 파트 미생성(IMAGE_GENERATION_REQUIRED)**
  - 상세 원본 재수집 단계는 원본만 배치한다. 그래서 비어 있는 AI 연출 파트는 "생성 필요"로 끝나고 재배치도 건너뛰었다.
  - 재수집 뒤에도 AI 연출 파트가 비어 있으면 생성을 한 번 더 한다. 이 코드는 복구 가능한 실패로 분류해 재배치가 이어지게 했다.
- **원고 보강 실패(선크림)**
  - "직접 사용 전에", "직접 사용할 때는", "직접 사용하시려면"처럼 사용 조건이나 안내를 말하는 문장을 허위 체험 단정으로 잘못 잡던 오탐을 고쳤다. "직접 써 보니"처럼 실제로 체험을 단정하는 문장은 계속 차단한다.
  - 이전 버전에서 저장된 원고가 품질 항목의 절반 이상에서 실패하면, 문단 몇 개만 고치지 않고 현재 작성기로 한 번 새로 작성한다.

## 검증

- `test:draft-reliability`에 추가: 오탐, 복구 로직 버전, 새로 작성 기준, 이미지 기준 완화(충분할 때 통과, 부족할 때 장수 안내).
- `verify-material-image-recovery`에 추가: AI 연출 파트만 1회 추가 생성하고, 원본 근거 부족에는 생성을 반복하지 않는지 확인.
- CI 단위 검사 전체, 소재 회귀 16개, 원고·이미지 관련 검사, Next.js 빌드 통과.
