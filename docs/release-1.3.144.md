# 1.3.144 — 이미지 검수 내부 모순과 같은 결과 재검수

새 소재를 MCP로 처음 준비하는 실제 시험에서, 비교와 세부 항목은 모두 통과인데 최종 `accepted`만 false인 응답을 확인했다. 이를 실제 상품 불일치로 기록하면서 완료된 개선 사진도 재검수 전에 복구 소진으로 막히던 문제를 수정한다.

검수 응답은 관찰·비교·세부 항목을 먼저 작성하고 마지막에 종합 판정을 내리도록 구성한다. 모든 필수 항목을 통과했는데 최종 판정만 불합격이면 자동 승인하지 않는다. 같은 원본·후보·본문 문맥으로 검수를 한 번만 다시 수행한다. 다시 모순되거나 입력이 달라지면 `REFERENCE_SCENE_REVIEW_INVALID`로 보류한다. 실제 형상·옵션·식별 문구·본문 주장의 부적합은 계속 차단한다.

이전 버전이 저장한 모순된 최종 판정만으로 새 유료 이미지 생성이나 개선 횟수 소진을 허가하지 않는다. 완료된 동일 요청은 기존 픽셀의 재검수로만 복구한다. 과거 요청·출력·검수 원문은 덮어쓰지 않는다. 최종 승인·발행 전 검수도 유지한다.

실제 시험의 최초 세 장 중 두 장은 실제 구조 오류로 탈락했고, 자동 개선 두 장 중 하나가 위 검수 모순으로 보류됐다. 따라서 이 변경을 최초 생성 무실패나 모든 소재 준비 성공의 증거로 사용하지 않는다. 같은 소재의 최종 복구 결과와 기존 원고·사진 보존은 배포 후 별도로 확인한다.
