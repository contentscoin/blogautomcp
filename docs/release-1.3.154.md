# 1.3.154

실제 MCP 소재 복구에서 확인한 인쇄 판독 불확실성을 줄입니다.

- 원본 선택은 서로 다른 원본에서 같은 식별 역할과 글자가 두 번 이상 관찰되고, 그 그룹이 유일하게 가장 클 때 비교 입력을 선택합니다. 다른 단독 판독 때문에 전체 과반을 못 채우는 경우에도 비교를 진행합니다. 동률·중복 사진·단독 불일치는 계속 보류합니다. 이는 사진 합격이나 재생성 허가가 아니며, 실제 두 이미지 대조와 독립 OCR 검증은 그대로 유지합니다.
- 글자를 읽기 전에 실제 제품·포장 표면을 먼저 찾도록 판독 지시를 보강합니다. 화면 모서리 로고나 큰 썸네일 문구를 작은 제품 인쇄 대신 읽지 않도록 합니다. 실제 실패 썸네일의 별도 시험에서는 외부 문구 오인이 재현되지 않았으며, 이것만으로 소재 승인을 의미하지 않습니다.
- 1.3.153의 검수 요청 형식 오류 수정과 트레이 완전 초기화 기능을 포함합니다. 초기화는 사용자의 명시적 확인과 작업 없음 확인 후에만 실행됩니다. 이번 검증에서는 사용자 초기화·블로그 발행·예약을 실행하지 않습니다.

기존 원고와 사진은 보존하며, 소재 준비완료는 해당 버전에서 필요한 단계 및 최종 검수를 실제 통과한 경우에만 기록합니다.
