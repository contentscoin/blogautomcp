# v1.3.101 — 네이버 로그인 세션 보존과 상태 확인 개선

네이버 작업 중 갱신된 인증 쿠키를 다음 작업에서도 사용하도록 저장합니다. 네트워크 오류나 권한 거절을 로그인 만료로 표시해 불필요한 재로그인을 유도하던 안내도 구분합니다.

- 서버에서 인증을 확인한 뒤 갱신된 쿠키를 저장합니다. 저장은 원자적으로 처리하며, 이전 작업의 늦은 응답이 새로 로그인한 계정의 세션을 덮어쓰지 못하게 합니다.
- 로그인과 작업이 같은 설정 경로를 사용합니다. 상태 확인도 응답의 쿠키 갱신을 반영합니다.
- 연결 오류·시간 초과·접근 거절·블로그 ID 미설정은 각각 안내합니다. 확인되지 않은 상태에서는 발행을 허용하지 않습니다.
- 일반 네이버 로그인은 기존 로그인 프로필을 활용합니다. 계정 변경 버튼에서만 로그인 쿠키를 초기화합니다.
- 세션 저장 실패가 이미 완료된 글 발행이나 예약의 결과를 실패로 바꾸거나 다시 실행하지 않습니다.

임시 세션과 모의 서버 응답으로 검증합니다. 실제 사용자 계정의 로그인, 글 생성, 예약과 발행은 릴리스 검증에서 실행하지 않습니다.

검증: 세션 회귀 99개, 작업 안전성 64개, 실제 컴포넌트의 독립 화면 검증 10개 통과. 안전 로그인 흐름·쇼핑 계정 분리 검증, TypeScript와 변경 파일 lint도 통과했습니다. 로그인 유지 기간 자체는 업데이트 후 실제 사용에서 확인해야 합니다.
