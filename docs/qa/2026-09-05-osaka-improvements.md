# 오사카 감사 후 개선 검증

## 구현

- 여행 장소 별칭 및 & 복합 지명 분리. 명시적 방문지가 있으면 상품명 숙박/옵션 토큰을 평가 근거에서 제외.
- 같은 문단의 바로 다음 문장까지 구체적인 대상과 장면 연결 인정. 문단/섹션 경계 및 다른 명시적 장소에서는 연결하지 않음.
- 출국 · 항공 정보가 마지막 방문지에 붙던 파싱 오류 수정.
- 필수 품질 실패 목록 qualityFailures 추가(구버전 저장 데이터와 호환되게 optional). 구조/안전 blockers와 분리. 이미지 반영 후에도 91점/70점인 실패를 low-evidence-density와 상세 사유로 유지.
- 원고 지침: 섹션별 분량/역할 다양화, 실제 날짜·동선 및 확정 불포함 유지, 미확정 호텔·선택관광의 근거 경계, 긴 상품명 복사 방지.
- 제휴 고지문이 본문 섹션에 섞여 있어도 본문을 보존하면서 고지 노드로 분리.
- 여행 썸네일 '브이로그'를 '가이드'로 변경.
- 이미지 지침에 이웃 섹션과 구별되는 대상/시점 및 정보형 이미지 성격 명시. 이미지 슬롯별 시작·완료·소요시간과 체크포인트 기록 시각 추가.

## 한계

이미지 시각적 중복을 자동 검출하는 모델/유사도 게이트, 섹션 의미 자동 재분류, 출처 enum 마이그레이션, UI 전체 준비시간 표시, 안전한 병렬 생성은 이번 변경에 포함하지 않았다. 이미지 지침 개선만으로 시각 품질 향상을 검증했다고 주장하지 않는다. 실제 모델 생성·속도 벤치마크는 실행하지 않았고 5분 완료를 보장하지 않는다. 코드 변경은 아직 설치 앱/공개 사이트에 배포하지 않았다. 기존 원고의 일정 순서·문체 자체를 재작성하지 않았으며 자동 승인/공개 발행도 하지 않았다.
