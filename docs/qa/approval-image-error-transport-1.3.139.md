# 1.3.139 승인 검수 오류 전달 수정

실제 MCP `POST_APPROVE_DRAFT` 작업에서 로컬 승인 API가 HTTP 422와 `PUBLISH_IMAGE_AUDIT_FAILED`를 반환했지만, PC의 오류 코드 목록에 해당 코드가 없어 `INVALID_INPUT`으로 오분류됐다. 원래 사진 검수의 거절 설명은 메시지에 남아 있었다.

명시적인 이미지 검수 실패 코드와 기본 안내를 PC 오류 계약에 추가했다. 실제 `localApi` 함수에 실패 응답을 넣어 정확한 코드·원래 메시지·HTTP 상태를 유지하고 승인 요청을 재전송하지 않는지 검증했다. 명시 `INVALID_INPUT`, 코드 없는 422, 알 수 없는 코드의 422, 기존 `CONTENT_BLOCKED` 동작도 확인했다. 실제 승인 gate에서 사진 거절이 나면 승인 저장을 호출하지 않는 반례도 포함했다.

이 수정은 기존 실패 작업을 성공으로 바꾸거나 승인·발행 조건을 완화하지 않는다. 1.3.138의 정본 이미지 정책 15개 파일, 기존 원고·사진·과거 작업 기록은 변경하지 않는다. Sites의 실패 결과 저장 구조는 이번 변경 범위에 포함하지 않는다.

배포 전 공급자/실제 브리지 회귀, 전체 타입 검사와 변경 파일 lint를 통과했다. 실제 배포·설치 및 소재별 승인 준비 결과는 별도 release 증거로 확인한다. 블로그 발행·예약은 수행하지 않는다.
