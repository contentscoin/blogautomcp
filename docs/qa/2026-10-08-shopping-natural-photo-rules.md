# 쇼핑 자연사진·큰 제목 썸네일 적용 검증

검증일: 2026-10-08. 이번 변경은 작업 폴더의 코드 수정이며 새 설치 파일 배포나 기존 예약 글 수정은 포함하지 않는다.

## 변경 결과

- 쇼핑 본문: 판매자 원본 1장 + 서로 다른 자연스러운 AI 사진 3장을 기본 배치. 추가 연출 컷은 허용하되 반복 원본으로 수량을 채우지 않는다.
- 설명 카드, 정보 패널, 장식 프레임, 삽입사진, 콜라주, 이미지 안 추가 설명문은 생성·적용·승인·최종 발행 검수에서 거부한다.
- 원본 참조의 상품 형태·옵션·색상·재질 대조와 자연스러움·추가 글자 없음·프레임 없음·단일 장면까지 11개 항목을 필수 검수한다. 검수 이력은 원본·결과 해시에 결속한다.
- 원본에는 판매페이지 원본 캡션, AI 사진에는 연출임을 알리는 캡션을 이미지 밖에 둔다. 실제 렌더 노드의 배치 순서도 검증한다.
- 썸네일: 1080×1080, 큰 사진 위 최대 두 줄, 132–170px 핵심 제목. 작은 부제·불릿·배지·설명 패널 제거. 쇼핑 편집 화면도 큰 제목만 편집하며 동작하지 않는 무드 선택은 숨긴다.
- 기존 썸네일 재사용은 크기만으로 허용하지 않고 새 출처 기록 또는 레이아웃 버전과 파일 해시로 확인한다.
- 전체 이미지 준비를 명시적으로 실행할 때만 이전 이미지 계획을 백업·전환한다. 원문·상품 링크·예약 정보는 유지하고 옛 이미지 파일도 삭제하지 않는다. 개별 컷 변경은 전체 유료 생성을 시작하지 않는다.
- 완료가 입증된 구버전 생성 기록은 보존하고 새 작업 폴더로 진행한다. 제출 불명·진행 중·잠금·손상 기록은 중복 요청을 막는다.

## 검증 근거

- CI에 등록된 단위 검증 26개 전체 통과. 이 중 material-regression은 하위 16개 묶음 통과.
- 새 자연사진 검증 묶음 9개 통과: 기본 배치, 명시적 계획 전환·백업, API 동작, 원본1+AI3 적용 및 실제 캡션·배치, 생성 재개 25개 반례, 참조 선택·검수, 승인 게이트, 최종 픽셀 감사, 썸네일 렌더링.
- 최종 픽셀 감사 48개 오프라인 시나리오, 검수 영수증 변조·정책 변경·거부 기록 회귀 통과.
- 실제 생성 모듈과 Sharp 렌더러로 sourceOnly 양쪽에서 썸네일을 확인했다. 이미지 제공자 프로세스 호출을 실패시키는 가드를 걸고 원격 생성 0회로 1080px 썸네일이 만들어짐을 검증했다.
- 루트 및 Sites TypeScript 검사 통과. 루트 src와 변경 스크립트, Sites MCP 라우트 ESLint 오류 0개. 기존 미사용 변수 경고는 남아 있다.
- Prisma 생성과 Next.js 프로덕션 빌드 통과. 정적 페이지 29개 생성 및 빌드 추적 완료.

## 범위와 남은 외부 확인

실제 유료 이미지 생성, 개별 상품 이미지 재생성, 네이버 예약 글 변경·발행은 실행하지 않았다. 썸네일 예시는 기존 판매자 원본 사진을 사용한 로컬 렌더러 검증 결과다.

별도 구형 test:thumbnail-studio는 쇼핑 1080px 검증 후 여행 문구·섹션 수의 오래된 기대값에서 실패한다. 해당 여행 구현은 이번 수정 범위가 아니며 CI의 여행 회귀 검사는 통과했다. 이를 전체 저장소의 모든 테스트가 통과했다는 주장으로 확대하지 않는다.
