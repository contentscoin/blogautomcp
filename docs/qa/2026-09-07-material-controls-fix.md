# 소재 보관함 동작 수정 — 1.3.38

상단의 소재 미리작성 버튼이 작성 전용 동작 없이 보관함을 열고 발행 안내를 표시했다. 실제 작성 버튼의 요청 결과도 발행 영역 아래에 있어 작업 시작 여부를 파악하기 어려웠다.

- 상단 버튼을 `미리작성할 상품 선택`으로 명확히 표시한다. prepare 요청으로 작성 영역을 열고 미준비 상품을 최대 10개 선택한다. 실제 생성은 사용자가 `소재 미리작성 시작`을 눌러 시작한다.
- 요청 접수·진행 개수·현재 단계·개별 실패를 작성 버튼 바로 아래에 표시한다.
- POST 응답의 작업을 즉시 목록에 반영한다. 후속 조회 실패는 접수 실패와 구분하고 중복 클릭은 한 번만 전송한다.
- 준비완료 수가 0개이면 일괄 선택을 비활성화한다. 목록 로딩과 소재 없음 상태를 구분한다.

검증: `node scripts/verify-material-controls.cjs`에서 실제 React 컴포넌트의 이벤트를 격리 실행하여 준비 단계 이동, 10개 선택, 이중 클릭 단일 POST, 접수/진행/오류 인접 표시, 준비완료 0개 비활성화를 확인했다. 브라우저 화면 분석은 실행하지 않았다.
