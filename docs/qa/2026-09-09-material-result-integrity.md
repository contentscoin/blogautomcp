# 1.3.47 소재 준비 결과 정합성 수정

- 자유 형식 문서를 재구성할 때 명시적으로 전달된 섹션 이미지 배치를 보존한다. 섹션 수가 맞지 않거나 업로드 목록에 없는 경로는 사용하지 않는다.
- 섹션의 이미지 목록과 실제 렌더 이미지가 다르면 승인을 차단한다.
- 소재 준비의 승인 호출 뒤 저장 상태를 다시 읽어 승인 시각, 이미지 부족, 실행 상태와 승인 게이트를 확인한다. HTTP 성공만으로 소재 완료를 보고하지 않는다.
