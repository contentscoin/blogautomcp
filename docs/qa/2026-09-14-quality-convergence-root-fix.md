# 초안 품질 수렴·승인 파이프라인 근본 수정 보고서

검사일: 2026-09-14 (KST)

이 보고서는 화면을 분석하지 않고 코드, 저장 패키지, 회귀검사, MCP 작업 결과와 배포 산출물을 기준으로 작성했다.

## 확인된 근본 원인

기존 흐름은 생성 직후 점수, 저장된 소재 재검수, 승인 판단이 서로 다른 입력과 기준을 사용했다. 생성기는 상품명·홍보 문구·이미지 수를 충분한 근거처럼 계산할 수 있었고, 저장 후 검수기는 실제 상품 사실과 문단 연결을 더 엄격하게 보았다. 이 때문에 생성 단계에서는 100점으로 통과한 소재가 저장 후 96점이어도 필수 항목에서 차단되는 상태가 발생했다.

재수집과 보강 경로에도 상태 손상 가능성이 있었다. 일부 재수집 결과가 기존 상품 근거를 통째로 교체했고, 보강 결과를 `post.md`와 `manifest.json`에 순차 저장해 중간 실패 시 해시가 맞지 않을 수 있었다. 자동 보강은 실패 항목과 무관한 문단까지 수정할 수 있었으며, 판매자 원문에서 파생한 문자열이 시스템 지시문으로 올라가는 경로도 있었다.

여행 상품은 상품 기간과 일정 범위를 비교하지 않아 장기 상품도 방문지 한 곳과 하루 일정만으로 출처가 충분하다고 판정될 수 있었다. 모델·인증·입력 오류까지 같은 방식으로 재시도해 실패 시간이 길어지는 문제도 함께 있었다.

## 적용한 구조 변경

1. 생성, 저장 재검수, 승인, 발행이 같은 정본 출처 스냅샷과 같은 필수 품질 게이트를 사용한다.
2. 가격·쿠폰·혜택·상품명·일반 홍보 문구·이미지 장수는 상품 기능 근거로 계산하지 않는다. 허용된 규격과 검증된 사실만 근거 밀도에 포함한다.
3. 쇼핑 상품의 신원, 원본 URL과 기존 근거 키를 보존한 경우에만 재수집 결과를 합친다. 일부 응답이나 다른 상품 리다이렉트로 기존 근거를 교체하지 않는다.
4. 여행 상품은 기간, 일정 일수와 핵심 방문지 범위를 함께 검사한다. 부족하면 글을 억지로 만들지 않고 출처 재수집 단계로 되돌린다.
5. 자동 보강은 실제 실패 항목과 연결된 문단만 수정한다. 수정 대상 밖 문단의 해시가 달라지면 후보를 거절한다.
6. 후보 원고는 점수 상승뿐 아니라 출처 충분성, 필수 실패 해소, 최종 발행 가능 상태를 모두 만족할 때만 채택한다. 실패한 보강은 기존 소재를 유지한다.
7. 본문과 매니페스트는 임시 패키지에서 완전히 검증한 뒤 원자적으로 교체하며, 교체 실패 시 기존 파일 세트를 복구한다.
8. 판매자 데이터와 파생 데이터는 신뢰하지 않는 사용자 데이터 블록에만 전달한다. 프롬프트 지시처럼 보이는 문장은 시스템 규칙으로 승격되지 않는다.
9. 인증·모델 버전·결정적 입력 오류는 즉시 종료하고, 일시 네트워크 오류와 출처 부족만 제한적으로 재시도한다. 자식 보강 프로세스에는 전체 프로세스 트리 종료를 포함한 제한시간을 적용한다.
10. MCP와 데스크탑은 `소재 준비 → 정본 검수 → 승인 가능 상태 저장 → 선택 발행`의 동일한 작업 경로를 사용한다. 준비 실패나 품질 미달 소재는 게시 요청으로 넘어가지 않는다.

## 글 보강과 이미지 생성 분리

실제 저장 패키지를 추적한 결과, 기존 보강 동작이 새 초안 제출과 같은 경로를 사용하면서 패키지 생성 시각, 섹션 ID와 이미지 작업 키가 모두 바뀌었다. 그 결과 이미 끝난 이미지까지 캐시에서 분리되고 새 작업으로 다시 시작됐다. 또한 일부 쇼핑 소재는 동일한 원본 사진 한 장을 분리하지 않은 큰 사각형 카드 상태로 여러 배경 위에 반복 합성했다.

텍스트 보강은 이제 기존 패키지에 대한 `PATCH` 수정으로 처리한다. 원문과 이미지 의도가 같으면 이미지 경로, 해시, 슬롯 ID, 완료 수와 생성 진행 상태를 그대로 보존한다. 이미지 설명이 실제로 바뀐 슬롯만 무효화하고 그 슬롯만 다시 만든다. MCP에도 품질 미달 시 전체 초안을 다시 제출하지 말고 이 수정 경로를 사용하도록 명시했다.

쇼핑 이미지 생성은 검증과 배경 분리가 끝난 상품 컷만 원본 팔레트에 넣는다. 서로 다른 안전한 원본을 먼저 쓰고, 사진 수가 부족하면 안전한 컷을 슬롯별 배경과 의도에 맞게 재사용한다. 분리되지 않은 전체 사진 카드, 최종 파일 바이트가 같은 중복 이미지, 실제 상품 컷을 확보하지 못한 결과는 승인 전에 차단한다. 부분 완료 상태에서는 이미 사용한 원본을 식별해 새 원본을 우선하며, 남은 슬롯만 재개한다.

## 정상 처리와 확인 필요 상태

충분한 상품·여행 근거가 있으면 초안 작성, 필요한 문단만 자동 보강, 저장 재검수와 승인 가능 상태 저장까지 자동으로 끝난다. 사람이 확인해야 하는 예외는 출처 자체가 부족하거나 상품 신원이 바뀐 경우, 인증·계약이 끊긴 경우, 모델·네트워크가 복구 불가능한 오류를 반환한 경우, 보강 후에도 필수 품질 조건을 만족하지 못한 경우로 제한했다.

낮은 품질의 글을 자동 승인하기 위해 기준을 낮추지 않았다. 자동 수렴이 실패하면 이전 정상 소재를 보존하고 구체적인 차단 코드와 항목을 반환한다.
