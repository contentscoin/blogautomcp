# Windows 1.3.142: 실패 단계의 근거와 이미지 참조 보강

상품 수집, 원고 검사, 사진과 본문의 일치 검사에서 확인된 네 가지 원인을 수정합니다.

- 판매자의 전원방식·안마부위·안마방식·부가기능·강약조절을 정규화 과정에서 보존합니다. 알려진 속성과 물리적 값만 허용하며 미확정 옵션 조건, 의료 효능, 알 수 없는 값은 자동 근거로 승격하지 않습니다.
- `방식`을 포함한다는 이유로 `디지털방식` 전체를 버리던 원고 근거 검사를 고칩니다. 기존 근거 개수와 품질 기준은 유지합니다.
- 사진의 외형과 다른 본문 문장은 서버의 정확한 문단·문장·사진 해시가 모두 맞고 순수한 외형 묘사인 경우에만 한 문장을 수정합니다. 수량·규격·기능·모델 등 보호 사실이나 모호한 문장은 보존하며 확인 필요로 남깁니다. 문장만의 문제를 해결하려고 정상 사진을 재생성하지 않습니다.
- 새 이미지 요청은 주참조 외에 같은 상품·옵션의 전체 형상과 로고 확대 사진을 최대 두 장 참조할 수 있습니다. 현재 판매자 출처·이미지·영수증 해시와 실제 사진 비교를 확인합니다. 생성 입력은 최대 세 장·8MiB입니다. 기존 요청의 참조·프롬프트·영수증은 유지하고, 종료된 거절 결과의 명시적 교체만 새 요청으로 처리합니다.
- 사진이 부족한 경우 현재 실패 슬롯의 형상·라벨 검수 원인을 남깁니다. 생성 사진의 거절을 원본 사진 부족으로 뭉뚱그리지 않습니다.

원고·정상 이미지·실행 이력을 보존하며, 원본 1장·자연스러운 연출 3장·썸네일 1장의 기준과 승인·발행 전 최종 검수를 유지합니다. 이 업데이트가 기존 실패 소재를 자동으로 준비완료 처리하거나 발행하지는 않습니다.

검증은 실제 실패 문장의 회귀, 소재 29개 회귀 묶음, 자연사진·참조·수집·원고 품질 검사와 독립 반례 검토로 수행했습니다. 실제 이어폰 원본을 사용하는 제한된 참조 선택에서는 형상·로고 사진이 각각 선택됐고 원본 파일은 변경되지 않았습니다. 모델은 잘못된 참조에서 문구를 오인할 수 있으므로 출처 경계와 최종 검수는 별도로 유지합니다. 참조 선택 검증은 새 사진 생성이나 실패 소재 전체의 준비완료를 입증하지 않습니다.
