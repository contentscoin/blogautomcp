# v1.3.78 — 새 PC 쇼핑커넥트 세션 연결 복구

- 새 PC에서 네이버 로그인 직후 브랜드커넥트 공식 SSO를 함께 완료하고 갱신된 세션을 저장한다.
- 쇼핑 상품 주소를 화면 링크에만 의존하지 않고, 로그인 계정 API가 반환한 공간과 카테고리로 찾는다.
- 실제 상품이 조회되는 카테고리를 우선하며, 여러 공간이 발견되면 임의 선택하지 않는다.
- 계정 API, SSO 후 API, 화면 링크 순서로 복구하고 401 로그인 만료와 403 권한 부족을 구분한다.
- 여행커넥트 계약, 이미지 품질 기준, 원고 승인 기준과 예약 발행 로직은 변경하지 않았다.
- macOS와 Windows 설치본의 서로 다른 리소스 경로를 각각 검증하도록 패키징 검사를 수정했다.

## 검증

- 타입 검사와 관련 lint 통과.
- 소재 회귀 검사 16개 통과. 이미지 배치 45개와 발행 이미지 검수 37개 시나리오 포함.
- 계정 API 기반 공간·카테고리 탐색, 상품이 있는 카테고리 우선, 다중 공간 차단, 401 분류를 오프라인 fixture로 검증.
- 현재 PC의 오래된 저장 세션은 브랜드커넥트 SSO 후 네이버 로그인 화면으로 돌아가며 `NAVER_SESSION_EXPIRED`로 정확히 분류됨.
- Windows/macOS 패키지 리소스 경로 fixture와 기존 Windows v1.3.77 설치본 구조 검사 통과.

다른 PC에서 실제 네이버 재로그인 후 쇼핑 상품이 조회되는지는 설치 후 한 번 확인해야 한다. 로그인한 계정에 쇼핑커넥트 공간이 없다면 자동화가 주소를 만들지 않고 권한 오류를 유지한다.
