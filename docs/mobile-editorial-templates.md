# 모바일 커넥트 편집 템플릿

## 작성자

페르소나는 실제 나이·직업·구매·여행 경력을 만들어내는 설정이 아니다. 확인된 상품 근거를 해석하는 관점과 말투다. 실제 체험 근거가 없는 글은 정보형임을 유지한다.

| 템플릿 | 작성 관점 / 말투 | 선택에 필요한 상품 근거 | 편집 리듬 |
| --- | --- | --- | --- |
| 쇼핑 생활 고민 해결형 | 생활 정리를 돕는 동료. 부드러운 요체, 구체적인 생활 상황 | 생활용품, 수납·청소·설치 문제와 연결되는 기능 | 짧은 상황 도입 → 관련 제품 사진 → 기능 설명 → 적용 조건 |
| 쇼핑 구매 비교형 | 차이를 짚는 구매 도우미. 간결한 조건문, 과장 없는 판단 | 비교 가능한 옵션·규격·구성·선택 조건 | 비교 기준 → 항목별 짧은 문단 → 상세 이미지 → 조건별 결론 |
| 쇼핑 제품 상세 해설형 | 구조를 풀어주는 제품 편집자. 기능과 의미를 명료하게 연결 | 작동 구조·소재·관리법 등 상세 근거 | 핵심 특징 → 설명 → 해당 상세 이미지 → 관리와 제약 |
| 여행 일정 따라가기형 | 이동 순서를 정리하는 일정 편집자. 순서와 장소가 명확한 요체 | 실제 일차별 일정과 방문 순서 | 일정 개요 → 일차별 소제목 → 풍경과 동선 → 준비 |
| 여행 여행지 매력형 | 장소를 소개하는 여행 편집자. 구체적인 풍경·활동 묘사 | 장소별 특징과 활동 근거 | 풍경 이미지 → 짧은 장소 소제목 → 활동 설명 → 다음 장소 |
| 여행 조건 비교형 | 동반자와 여행 속도를 살피는 여행 상담자. 조건과 제약 중심 | 숙박·동반자·포함/선택 조건 | 적합한 여행자 → 조건별 설명과 사진 → 추천·비추천 판단 |

## 공통 모바일 규칙

- 본문은 왼쪽 정렬. 긴 본문 가운데 정렬과 양쪽 정렬을 쓰지 않는다.
- 문단은 보통 1~2문장. 완결된 의미 단위에서 나누며 글자 수에 맞춘 강제 줄바꿈은 금지한다.
- 문단 사이 빈 줄 하나. URL·숫자·단위를 중간에서 분리하지 않는다.
- 소제목은 짧고 구체적으로 작성하며 매번 같은 질문·번호·이모지로 시작하지 않는다.
- 흰 배경, 진한 본문, 글당 하나의 강조색. 긴 문단 전체를 색칠하지 않는다.
- 글꼴 나눔고딕, 본문 16px, 소제목 19px, 캡션 13px. 2026-09-05 실제 네이버 메뉴에서 확인한 지원값이다(20px 옵션 없음).
- 줄간격은 180%. 네이버에서 실제 확인된 편집 기능만 조작한다.
- 팔레트는 실제 지원 색상으로 제한한다: 쇼핑 고민 #00554c, 비교 #003960, 상세 #823f00; 여행 일정 #004e82, 풍경 #245b12, 조건 #4f0041. 본문 #333333, 캡션 #555555.
- 굵게는 짧은 핵심 문장에만, 밑줄은 링크에만 사용한다. 형광펜·장식 인용구를 모든 섹션에 반복하지 않는다.
- 모바일 비교는 넓은 표 대신 항목별 세로 문단을 사용한다.
- 사진은 섹션 ID 연결을 유지한다. 사진 속 글자가 작아지는 3열 콜라주보다 단일 이미지를 우선한다.
- 캡션은 실제 이미지와 근거가 있는 경우에만 작성한다. 생성 이미지를 실물·숙소 실사진으로 설명하지 않는다.
- 상품 링크와 고지 위치, 근거 검증, 섹션별 이미지 검증은 유지한다.

## 자동 선택 원칙

상품명과 검증된 상세 정보를 함께 사용한다. 단순 홍보 키워드만으로 비교형이나 일정형을 선택하지 않는다. 상세 근거가 부족하면 쇼핑은 생활 고민 해결형, 여행은 장소 소개형의 보수적인 기본값을 사용하고 없는 특징을 채우지 않는다. 선택 결과와 이유를 작성 문맥과 렌더 문서에 함께 보존해야 한다.

템플릿은 구성의 안내다. 기존의 확인된 일정 순서·필수 고지·이미지 연결을 임의로 재배열하지 않는다. 화면 크기에 따른 정확한 줄 수를 보장하지 않으며 360~430px 폭에서 가로 넘침과 읽기 흐름을 확인한다.

## 검증 범위

선택 규칙, 최초 작성/재작성 문맥, 렌더 문서의 스타일 보존, 문단 분리, 이미지 섹션 연결을 자동 검사한다. 로컬 미리보기와 실제 네이버 편집기 검증은 별개다. 네이버에서 색상·크기·굵게 적용과 저장 후 유지가 관찰되지 않았다면 실제 적용 완료로 표시하지 않는다.
