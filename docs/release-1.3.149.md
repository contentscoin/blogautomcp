# 1.3.149 — 생성 참조 보강과 사진 검수·단계별 복구 안정화

확인된 인쇄 결함을 보완할 때는 검증에서 실제 문자를 확인한 선명한 판매자 원본을 개선 생성의 필수 참조로 전달합니다. 작은 착용 사진만으로 다시 생성하던 경우를 줄이기 위한 변경입니다. 기존 주참조는 외형·배치를, 추가 원본은 실제 상품 표면의 인쇄만 안내합니다. 확인된 원본 문자 외에 브랜드 철자를 추측하지 않으며 설명 문구·카드·프레임을 추가하지 않습니다. 필수 참조의 원본 기록·파일 해시·용량을 확인할 수 없으면 전송 전에 중단합니다.

실제 검증에서 사진에 쓰인 브랜드 문자를 검수 모델이 기대한 상품명으로 잘못 읽어 승인한 사례를 보강합니다. 선택된 판매자 원본과 후보 사진의 실제 상품 인쇄 영역을 연결하고, 제품명이나 기대 철자를 입력하지 않는 로컬 문자 판독으로 읽히는 브랜드·모델 표기를 대조합니다. 원래 모델의 관찰과 판정은 보존하며, 별도 픽셀 판독 근거를 함께 기록합니다.

원본과 후보의 고신뢰 문자 판독이 확인되고 실제 식별 표기가 다를 때만 최종 검수에서 거절합니다. 외부 홍보 배지, 다른 부품, 무표기 상품과 읽을 수 없는 작은 표식은 오타 복구 권한으로 사용하지 않습니다. 검사는 이미지 준비·최종 검수 작업에 한정하고 파일 해시에 결합한 결과를 재사용합니다.

검수의 문자 관찰이 주석을 포함하거나 영역을 잘못 잡아 독립 판독과 맞지 않을 때는, 원본과 후보를 각각 한 장씩 별도로 관찰합니다. 이 관찰에는 기대 상품명·브랜드·앞선 전사를 전달하지 않으며, 각 한 번의 관찰과 원시 응답을 보존합니다. 전체 단어 영역이 최초 관찰 위치에 대응하고 독립 문자 판독과도 일치해야 복구 근거로 사용할 수 있습니다. 불명확·실패 결과를 자동으로 반복 요청하지 않습니다.

상품의 보이는 구조는 참조 사진과 실제로 관찰한 서로 다른 특징으로 대조합니다. 시중의 유일한 SKU나 사진에 가려진 부위까지 인증하도록 요구하지 않습니다. 확정 옵션과 판매 페이지의 색상·사이즈 범위를 구분하고, 사이즈만 정해진 상품의 색상을 판매자 안내 순서로 추정하지 않습니다. 실제 확정 옵션 충돌과 본문이 주장한 구성품·수량의 불일치는 계속 차단합니다.

실제 최종 검수는 네 항목을 각각 요청합니다. 형태 검사는 후보와 해당 슬롯의 주참조 두 장에서 보이는 구조를 비교하고, 인쇄 검사는 실제 상품명의 철자를 전달하지 않는 개별 관찰과 같은 부위·표면의 대조를 사용합니다. 본문 설명 검사는 후보 한 장과 원래 줄바꿈·위치가 유지된 실제 게재 문단을 봅니다. 카드·프레임·썸네일 검사는 후보 사진의 픽셀만 봅니다. 다른 색상 갤러리가 형태 판정을 오염시키거나, 본문의 설명을 사진 안에 인쇄된 문구로 착각하는 문제를 줄입니다. 실제 옵션·구성품 충돌, 형태 결함, 식별 구조를 가리는 문구와 본문 카드·프레임은 계속 차단합니다. 실제 외형·본문 설명·사진 형식의 부정 판정은 전체 승인을 보류하며 원시 응답을 보존합니다. 인쇄의 관찰 한계와 실행 오류는 별도로 구분합니다.

자체 참조와 후보가 각각 실제 관찰에서 무지인 같은 면을 보여 주면 다른 색상·다른 면의 로고를 요구하지 않습니다. 후보와 모든 참조가 각각 명확히 무지로 관찰된 상품은 인쇄 대조의 적용 대상이 아님을 기록합니다. 읽을 수 없는 표식은 무지로 간주하지 않으며, 이 구분으로 외형·본문·배치 검사를 생략하거나 개선 생성을 허가하지 않습니다.

정상 판매자 원본이라도 해당 문단의 외형 설명을 보여 주지 못할 수 있습니다. 실제 최종 검사에서 현재 원본 슬롯에 결합된 문단 불일치만 확인되면, 서명된 증거에 따라 같은 상품의 검증된 판매자 원본을 한 번 다시 배정합니다. 기존 원고와 사진 파일은 보존합니다. 이 조치는 AI 생성·원고 수정 권한이 아니며, 배정 후 전체 검사를 다시 수행합니다. 다른 생성 사진이 바뀌었다는 이유로 원본 재배정 횟수를 초기화하지 않습니다.

상품 표기가 빠진 경우는 철자가 다른 경우와 별도 증거로 기록합니다. 실제로 같은 부위·표면·색상이 드러나고 원본의 전체 인쇄 위치에 해당하는 후보 영역이 명확히 비어 있어야 합니다. 원본의 문자는 독립 판독으로 확인하며, 후보 OCR의 실패만으로 표기가 없다고 판단하지 않습니다. 반사·흐린 표식·가림·다른 면·불확실한 대응은 추가 생성의 근거로 쓰지 않습니다.

작거나 가려져 상품 인쇄를 충분히 읽을 수 없는 경우는 인쇄를 인증한 것으로 처리하지 않고 ‘인쇄 미검증’ 경고로 남깁니다. 현재 외형·본문 설명·사진 형식의 실제 검사가 모두 통과하고 본문이 그 문자를 읽을 수 있다고 주장하지 않으며 유효한 관찰 기록이 있을 때만 이 경고가 준비 완료를 막지 않습니다. 같은 사진에 이미 확인된 구체적인 인쇄 결함이 있으면 경고로 덮지 않습니다. 읽히는 오타·명확한 표기 누락·확정 옵션 충돌과 실행·응답·첨부 오류는 계속 차단합니다. 이 경고는 정상 사진 교체나 추가 생성의 근거가 아니며, 작은 인쇄까지 정확하다는 보증도 아닙니다.

현재 원고·원본·실제 생성 요청에 결합된 서버 증거와 단일 완료 요청이 확인되어야 한 번의 개선 생성으로 이어집니다. 서명된 증거는 판정 당시의 원고·배정 상태도 변경 불가능한 파일로 보존하여, 이후 원본을 다시 배정했을 때 이전 문맥의 증거를 잘못 재사용하지 않습니다. 정상 사진과 기존 원고·생성 기록은 유지하고, 개선 결과도 원본 비교와 전체 최종 검수·승인을 다시 통과해야 합니다. 소재 준비는 발행·예약을 실행하지 않습니다.

동일 슬롯에 과거 완료 사진이 여러 장 남아 있는 경우에는 현재 배정 사진의 파일 해시·출처 경로·전체 메타데이터가 유일하게 가리키는 요청만 복구 대상으로 선택합니다. 같은 주참조와 현재 문맥을 사용한 과거 완료 요청은 변경 불가능한 해시 목록에 묶어 보존합니다. 진행 중·미확정·다중 후보·중복 출처·다른 문맥은 계속 보류하며, 이미 소비된 개선 생성 횟수를 초기화하지 않습니다. 생성 직후 검사에도 같은 인쇄 검사를 연결합니다.

Windows 저장 재시도와 임시 파일 정리는 파일 식별번호를 정확한 큰 정수로 비교합니다. JavaScript의 안전한 정수 범위를 넘는 식별번호가 반올림되어 다른 파일과 같아지는 경우에도 기존 파일이나 다른 작업의 임시 파일을 지우지 않습니다. 파일 내용·수정 시점·생성 시점 비교와 제한된 공유 잠금 재시도는 유지합니다.

실제 네 소재의 복구 결과와 배포·설치 완료는 해당 실행의 검증 결과로 별도 확인합니다.
