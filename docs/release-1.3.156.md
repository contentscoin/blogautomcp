# 1.3.156

- 과거 인쇄 결함 검수에 쓰였던 선명한 판매자 원본을 다시 찾습니다. 상품·원본 스냅샷·문단·대상 사진이 그대로인 서명 기록만 탐색에 쓰고, 현재 수집 기록과 파일을 다시 검증합니다. 최대 다섯 비교 원본 중 남는 자리 하나만 사용합니다.
- 과거 판정은 현재 승인이나 이미지 재생성 권한으로 전환하지 않습니다. 실제 사진과 글자 검수는 새로 수행합니다.
- 본체 색상과 로고·포장 색상을 혼동하지 않도록 원본 선택과 최종 본문 사진 검사 지침을 명확히 했습니다. 조건부 구매 안내는 사진의 외관 주장으로 취급하지 않습니다.
- 판매자 갤러리의 서로 다른 구성품 글자가 일치하지 않으면 정확히 연결된 주 원본을 검사합니다. 생성 사진 글자를 기준으로 원본을 고르지 않으며, 일치·결함 판정에는 기존의 대조 검수와 OCR 근거가 필요합니다.
- 포장 상자 등 별도 구성품에 있는 글자를 기기 표면에도 요구하지 않도록 구분합니다. 실제 위치 분리와 두 개 이상의 대응 구조, 상품·본문·형식 검사가 확인된 경우에만 기기 인쇄 상태를 미확인 경고로 남깁니다. 확정된 인쇄 결함, 상품 불일치, 변조된 검수 자료는 계속 차단합니다.

검증: 과거 원본 탐색의 서명·대상·스냅샷·수집 기록 오류 및 원본 보존 검사; 기존 갤러리 77개, 부분 복구 98개, 생성 이력 72개, 독립 사진 검수 933개 회귀 검사. 실제 크림색 이어폰 사진에서 검은 본체라는 주장은 거절, 조건부 색상 확인 안내는 통과하는 별도 진단 확인. 진단은 승인 자료로 사용하지 않습니다.
