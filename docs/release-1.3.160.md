# 1.3.160

독립 사진 관찰에서 이미 정규화된 글자 좌표를 후속 검수가 다시 환산하는 오류를 줄였습니다. 글자 위치가 확인된 경우 출력 스키마가 원래 좌표 값만 허용하고, 수신 검증은 좌표의 순서까지 원본과 정확히 대조합니다. 새로 관찰해야 하는 빈 면·가려진 위치는 기존 관찰 규칙을 유지합니다.

배열 전체를 enum으로 고정하는 방식은 사용하지 않습니다. 지원되는 정수 enum을 사용하며 실제 모델 호출로 규격 수용과 좌표 보존을 확인했습니다. 다른 좌표·순서 변경·실제 글자 불일치·미확정 판정은 승인으로 바꾸지 않습니다.

현미경 소재는 1.3.159의 실제 MCP 보완에서 승인 준비를 완료했습니다. 이어폰은 후속 복구 대상입니다. 기존 원고·정상 이미지를 보존하며 초기화·발행은 실행하지 않습니다. 배포·설치와 실제 소재 준비 결과는 별도 확인합니다.
