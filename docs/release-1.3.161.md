# 1.3.161

보조 판매자 사진의 불완전한 글자 판독 하나가 전체 사진 검사를 막는 경로를 보완했습니다.

- 확실히 수신한 잘못된 형식의 판독 응답만 같은 사진·같은 질문으로 한 번 더 확인합니다. 원본 응답을 보존하고 전체 시간·횟수를 제한합니다. 유효한 판독 불가나 통신 결과 불명은 반복 요청하지 않습니다.
- 최종 제품 구조·본문 주장·사진 형식 검사가 통과한 경우에만, 보조 사진의 계속된 형식 오류를 원문·해시·요청과 함께 진단으로 보존하고 유효한 기준 사진으로 검사를 이어갑니다. 후보 사진과 주 기준 사진은 제외할 수 없습니다.
- 빠진 응답을 ‘인쇄 없음’으로 처리하지 않습니다. 모든 원본이 인쇄가 없다는 판정에는 완전한 관찰이 필요합니다. 실제 글자 오류와 검증된 다른 부적합 판정은 유지합니다.

현미경은 1.3.159에서 실제 승인 준비를 완료했습니다. 이어폰만 후속 복구하며 기존 원고·정상 사진을 보존합니다. 초기화·발행은 실행하지 않습니다.
