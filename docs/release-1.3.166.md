# 1.3.166

- 제품 형태·본문과 사진의 관계·사진 형식 검사가 통과한 사진에서, 작은 글자 판독 불가와 실제 인쇄 결함을 구분합니다. 확정된 오탈자와 노출된 대응 인쇄 누락은 계속 차단합니다. 불확실한 관찰은 원문과 OCR 기록을 보존한 경고이며 글자 일치 인증이나 추가 생성 권한이 아닙니다.
- 검수 정책 변경 전에 정상 완료된 단일 복구 사진은 기존 서명·봉인·원본·본문·요청 결과를 확인한 뒤 그 사진만 다시 검수합니다. 기존 생성 한도를 되돌리거나 새 요청으로 전환하지 않습니다.
- 확실히 수신된 잘못된 형식의 검수 응답은 같은 입력으로 한 번만 복구합니다. 실제 부적합 판정이나 전송 결과가 불명확한 요청은 이 방식으로 반복하지 않습니다.
- 변경 없는 사진의 정상 검사 결과를 서명된 로컬 캐시로 재사용합니다. 원본·본문·판정 규칙이 바뀌거나 서명이 맞지 않으면 재검사하며 승인 전 최종 검수는 유지합니다. 강제 검수의 실패·인증 오류 뒤에는 이전 정상 캐시를 재사용하지 않으며, 동일 요청의 동시 실행도 직렬화합니다.

기존 원고와 정상 이미지를 보존합니다. 이 업데이트는 초기화·예약·발행을 실행하지 않습니다.
