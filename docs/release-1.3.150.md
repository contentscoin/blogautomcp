# 1.3.150

최종 인쇄 검사의 관찰 한계와 확정된 결함을 구분합니다. 같은 슬롯의 원본 비교에서 인쇄 누락이 의심됐더라도, 별도 선명한 원본과의 비교에서 같은 부품·면·옵션을 모두 확인하지 못하면 누락이 확정된 것은 아닙니다. 현재 외형·본문 설명·사진 형식 검사가 모두 통과하고 본문에 정확한 문자 판독 주장이 없으며, 두 비교의 응답·첨부·좌표와 원본 수집 증거가 유효할 때만 ‘인쇄 누락 의심·미확정’ 경고로 남깁니다. 선명한 원본도 같은 선택 상품의 본체라는 별도의 실제 외형 검사를 통과해야 합니다.

이 경고는 인쇄가 정상이라는 판정이나 정확성 보증이 아닙니다. 실제 인쇄가 빠졌을 가능성은 남습니다. 첫 비교의 누락 의심과 두 번째 비교의 미확정·부정 응답을 모두 보존하며, 사진 교체·추가 생성·문자 인증 권한을 만들지 않습니다. 경고 종류와 증거 지문은 최종 승인 서명에 묶어 저장하고, 같은 검수 결과를 재사용해도 동일한 경고를 표시합니다.

읽을 수 있는 오타와 독립 판독으로 확인된 불일치, 별도 비교에서도 확정된 인쇄 누락, 실제 부품·면·옵션의 부정 판정, 정확한 인쇄를 증명한다는 본문 주장, 원본·첨부·응답·좌표·판독 실행 오류는 계속 차단합니다. 같은 사진에 이미 저장된 확정 결함이나 손상된 결함 기록은 정책이 바뀌어도 미확정 경고로 해제하지 않습니다. 정상 원고·사진과 과거 원시 응답은 보존합니다.

새 경고는 현재 최종 검사의 실제 증거에만 적용합니다. 생성 직후 검사에 새 모델 질문이나 재시도 권한을 추가하지 않으며, 필요한 선택 상품 증거가 없으면 계속 보류합니다. 실제 결함의 개선 생성은 기존의 서명된 증거·유일한 원래 요청·단 한 번의 개선 요청·검증된 인쇄 참조 조건을 그대로 따릅니다. 개선 결과도 원본 비교와 최종 전체 검수·승인을 통과해야 합니다.

독립 관찰에서 이미 확정된 원본 단어 영역과, 읽을 수 있는 후보 단어 영역은 검수 응답 규격에도 고정해 좌표를 다시 적는 실수를 줄입니다. 표기가 없거나 읽을 수 없는 후보의 대응 영역은 계속 실제 관찰로 정해야 하며, 판단의 부정·미확정 값은 바꾸지 않습니다. 이전 149 원시 기록은 150의 새 응답 규격과 동일한 호출로 간주하지 않고 로컬 재검산 자료로만 사용합니다. 150 실제 실행 호환성과 최종 승인은 설치 후 확인합니다.

독립 문자 관찰의 응답도 두 가지 일관된 형식으로 나눕니다. 제품 자체에 읽히는 인쇄가 있을 때만 실제 단어·좌표·인쇄 위치를 함께 반환하고, 없거나 불명료하면 단어와 좌표를 비운 관찰을 반환합니다. 판매자 사진 위의 외부 회사 로고를 제품 인쇄로 옮기지 않으며, 이전에 나온 ‘글자는 읽히지만 위치는 관찰하지 못했다’는 모순 응답은 수정하거나 재시도하지 않습니다. 새 응답 버전과 요청 지문을 사용하므로 과거 원시 응답을 새 관찰로 이름만 바꿔 사용할 수 없습니다.

확정된 인쇄 결함과 미확정 검수 오류가 서로 다른 사진에서 함께 나와도, 서버가 현재 원고·슬롯·사진·정책에 정확히 연결된 서명 증거를 확인한 사진만 한 번의 개선 경로로 부분 복구할 수 있습니다. 클라이언트가 보낸 이미지 키·원본 경로·증거·범위 지정은 받지 않으며, 이미지 잠금을 얻은 뒤 전체 소재 지문을 다시 확인합니다. 미확정 사진과 원고는 그대로 보존하고, 확정 증거가 없으면 생성하지 않습니다.

부분 복구는 전체 소재의 준비 완료가 아닙니다. 같은 호출에서 일반 이미지 채우기·원본 재수집·배치 변경·추가 승인으로 이어지지 않으며, 최초 검수 실패와 부분 복구 실패도 각각 남깁니다. 로그인·사용량 한도·응답 불명 상태는 원래 실패 코드로 중단하고, 응답이 끊긴 복구 요청은 재전송하지 않습니다. 전체 소재는 미해결 검수와 최종 승인을 완료하기 전까지 계속 보류됩니다.

검증된 소재 준비와 실제 발행은 별도 단계입니다. 배포·설치와 실제 네 소재의 완료 여부는 해당 실행 결과로 확인하며, 준비 작업은 발행·예약을 실행하지 않습니다.

썸네일의 사진 형식 검사는 실제 이미지와 역할만 받습니다. ‘구매 전 확인’, ‘기능 체크’처럼 사양을 단정하지 않는 제목을 판매자 설명에 그대로 있는지 대조하지 않습니다. 썸네일에 실제 수량·성능·인증·효능을 단정하는 문구가 있으면 문장·사진 근거 검사가 계속 확인합니다. 본문 사진에 설명 프레임이나 문구를 추가할 수 있는 예외를 만들지는 않습니다. 본문 형식 검사 재사용도 본문 역할로 확인하므로 썸네일에만 필요한 헤드라인 조건 때문에 정상 본문 사진을 반복 검사하지 않습니다.

최종 승인에 미검증 경고가 포함되면 현재 승인 서명과 원고·사진·원본·정책을 다시 확인한 뒤 소재 목록과 미리보기에 경고 종류를 표시합니다. 오래되거나 손상된 승인, 변경된 사진의 경고는 현재 승인으로 표시하지 않습니다. 목록의 변하지 않은 요약은 재사용하여 유휴 상태에서 사진 파일을 반복 읽지 않습니다. 경고 표시가 준비 상태나 발행 권한을 부여하지 않습니다.

원본 한 장에 기기와 인쇄된 포장 상자가 함께 있으면, 상자의 단어를 기기 전면의 필수 인쇄로 옮겨 판단하지 않도록 공간 범위를 구분합니다. 기존 한 번의 국소 위치 검사에 독립 관찰한 원본 단어의 고정 좌표만 전달하고, 실제 비교하는 면 전체의 경계와 서로 다른 두 구조의 대응·분리 근거를 받습니다. 단어 영역과 면 영역이 조금이라도 겹치거나 부품·면·옵션 중 하나가 미확정·부정이면 이 분류를 허용하지 않습니다. 현재 외형·문장·형식 검사가 모두 통과한 동일한 무인쇄 면과 별도 구성원의 인쇄임을 확인한 경우에도 결과는 ‘인쇄 미검증’ 경고이며, 문자 인증이나 교체·추가 생성 권한을 만들지 않습니다. 원본의 읽히는 단어와 공간 검사 원시 응답은 그대로 보존합니다.

반대로 후보 사진 배경의 판매자 그래픽을 제품 자체 인쇄로 잘못 읽은 경우에도 관찰 원문을 고치지 않습니다. 현재 외형·주장·형식 검사가 통과한 상태에서 기존 한 번의 위치 검사로, 후보의 고정 단어 영역과 양쪽 사진의 실제 외부 그래픽·물리 제품 전체 경계를 비교합니다. 원본에도 실제로 대응하는 같은 외부 그래픽이 있고, 단어와 제품·자체 포장·다른 실물 구성원이 양쪽에서 모두 겹치지 않으며 서로 다른 구조 두 개가 대응하는 경우에만 인쇄 정확성을 인증하지 않는 경고를 남깁니다. 다른 실물의 인쇄·제품 뒷면·반사 인쇄·새로 추가된 다른 그래픽·미확정 관찰은 이 분류로 통과하지 않습니다. 추가 질문·문자 인증·재생성 권한은 없고, 같은 사진의 과거 확정 결함이나 손상된 기록은 썸네일 재배치·검수 결과 재사용으로 해제할 수 없습니다.
