# 1.3.143 — 최초 작성의 이미지 계획과 참조 기록 안정화

같은 상품 사진을 재수집할 때 출처 기록의 시각을 덮어써 기존 이미지 요청이 스스로 무효화되던 문제를 수정했다. 기존 출처 원문은 유지하고 재수집 시각은 별도 관측에 기록한다. 이미 손실된 출처는 원래 SHA와 정확히 일치하는 과거 원문이 있을 때만 복구한다.

새 사진은 실제 참조에서 관찰한 착용·배치 상태, 보이는 면, 가려진 부분과 판독 가능한 식별 문구를 기준으로 기획한다. 착용 사진만 보고 맨제품이나 보이지 않는 허리밴드를 새로 요구하지 않는다. 생성 사진의 역할은 글 전체 섹션 번호 대신 생성 슬롯 순서로 정한다. 보완 작성에도 검증 원본과 현재 사진 계획을 전달한다.

확정 완료한 본문 사진이 실제 비교 검수에서 거절되고 개선된 계획이 있을 때만 새 시도를 한 번 허용한다. 종료 기록·출력 전체·원본·실제 게시 문맥을 확인하며, 전송 여부가 불명확한 요청이나 검수 응답 오류는 새 생성 권한이 되지 않는다. 정상인 사진과 원고는 보존한다. 이미 완료된 썸네일 원본에 글자만 다시 그리는 복구는 새 생성 없이 유지한다.

ChatGPT 직접 이미지 작업도 최대 3장 참조를 지원한다. 첨부가 다른 파트는 `post_get_draft(referenceSectionId)`로 해당 파트만 조회한다. 참조 순서·역할·해시와 실제 첨부가 일치해야 생성 가능 상태를 반환한다. 새 기능은 PC 1.3.143 이상에서 접수하고, 기존 1~2장 작업은 호환을 유지한다.

최종 형상·옵션·라벨 검사와 승인·발행 전 검수는 유지한다. 오래된 요청에 정확한 생성 문맥이나 출처 원문이 없으면 자동 해제하지 않는다. 기존 실패 소재 전체의 복구나 실제 새 사진 생성 성공률을 이 변경만으로 보장하지 않는다.
