# v1.3.89 — 거절 이미지 정밀 복구와 상품 단위 재사용 차단

1.3.88은 최종 감사에서 거절된 이미지를 제거해 소재가 멈추지 않게 했지만, 바로 복구할 수 있는 AI 연출 이미지도 먼저 제거·완화 경로로 보냈다. 또한 다른 상품이나 혼합 옵션으로 판정된 원본이 다른 문단 후보로 다시 선택될 수 있었다.

- **거절된 이미지만 다시 준비**
  - `repair_rejected` 작업은 최종 감사에서 거절된 슬롯만 대상으로 한다.
  - 원본 교체, 기능 팩트 카드, 상품 원본을 잠근 AI 생활 장면 재생성을 현재 이미지 규칙으로 다시 수행한다.
  - 전체 이미지 생성은 반복하지 않으며, 복구 실패나 두 번째 거절 때만 기존 제거·재계획 경로로 넘어간다.
- **잘못된 상품·혼합 옵션의 상품 단위 차단**
  - 상품 불일치, 공지 패널, 본문에서 허용하지 않은 혼합 옵션은 같은 소재의 모든 문단에서 재사용하지 않는다.
  - 일반 상품 사진이 기능 문단을 증명하지 못한 경우는 해당 문단에만 묶어 거절한다. 전체 모습 문단에서 쓸 수 있는 원본까지 막지 않는다.
- **복구 횟수 유지**
  - 거절 이미지 교체는 동일한 원고·근거에 한 번만 실행한다.
  - 새 이미지나 새 판정이 생기면 복구 서명이 달라져 다음 단계가 이어지고, 같은 실패를 무한 반복하지 않는다.

## 검증

- 최종 이미지 거절 기록: 문단 범위와 상품 범위 차단, 새 승인에 의한 해제, 동시 변경 보호.
- 소재 이미지 복구: 거절 슬롯 1회 교체, 두 번째 거절 재계획, 인증·혼합 오류 중단, 전체 생성 비반복.
- 이미지 재계획·팩트 카드·상품 원본 검토·최종 시각 감사 회귀 검사와 TypeScript 검사.
