# 1.3.170

- 상품별 선택 옵션·확인 사실·독자의 구매 고민·장점과 제약을 짧은 공통 브리프로 정리해 Desktop과 MCP 작성 계약에 사용합니다. 짧은 글 구성에서도 선택한 상품 사실이 누락되지 않도록 배정합니다.
- 본문 사진의 목표 장수와 각 슬롯의 촬영 목적을 생성 하네스에 연결합니다. 핵심 외형과 옵션을 보존하면서 자연스러운 구도·배경을 설계하고, 본문 설명 프레임·패널·콜라주를 금지합니다. 썸네일은 전체 사진과 큰 한국어 핵심 문구를 사용합니다.
- 일반 상품 사진의 기본 검수를 묶음 종합 검사로 줄입니다. 작은 인쇄·조명·가림 때문에 별도 OCR과 인쇄면 인증을 반복하지 않으며, 명확한 상품·옵션 불일치, 큰 왜곡, 금지 레이아웃과 근거 없는 사진 주장은 차단합니다.
- 같은 원고·사진·상품 근거의 유효한 기존 성공 영수증을 검증해 재사용합니다. 확정 실패와 기술 오류를 구별하고 정상 결과물을 새로 생성하지 않습니다.
- Codex가 반환하는 단계별 사용량·실행 시간·호출 회차를 기록합니다. 미제공 사용량을 0으로 표시하지 않으며 프롬프트 원문·사진·인증정보를 기록하지 않습니다.

기존 원고와 정상 이미지를 보존합니다. 발행·예약·완전 초기화는 실행하지 않습니다.
