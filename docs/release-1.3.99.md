# v1.3.99 — 보완 필요 소재 일괄 보완 및 검증

저장된 글에서 원고 품질, 이미지 또는 승인이 부족한 소재를 한 번에 보완할 수 있습니다. PC 소재 보관함과 Sites 대시보드의 **보완 필요 소재 전체 보완·검증** 버튼, 플러그인의 `materials_repair_blocked` 명령을 제공합니다.

- 기존 글이 있는 보완 필요 소재만 선정합니다. 새 글 작성과 실패 글 전체 재작성은 기존 기능으로 진행합니다.
- 수정 전에 기존 패키지를 백업하고 원고와 이미지는 부족한 부분만 보완합니다.
- 현재 원고·이미지 품질검사와 최종 승인을 통과한 소재만 준비 완료로 저장합니다. 발행이나 예약은 실행하지 않습니다.
- 준비 완료·게시·예약·실행 중·결과 불명확 소재는 보호하며, 같은 요청의 재시도는 같은 작업으로 이어집니다.
- 항목별 진행 단계와 검증 결과, 남은 보완 사유를 확인할 수 있습니다.

새 Sites 버튼과 플러그인 명령은 PC 앱 1.3.99 이상에서 사용할 수 있습니다.
