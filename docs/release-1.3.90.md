# v1.3.90

- Windows 패키지의 Electron 메인 엔트리를 `resources/app` 바깥의 독립 런타임 복제본으로 실행해, 느슨한 앱 파일 중 `scripts/electron/main.cjs`가 누락된 설치에서도 시작 파일을 안정적으로 찾습니다.
- 메인 엔트리, 자동 업데이트 모듈, 런타임 정책 파일을 설치 리소스에 별도로 복제하고 원본과 바이트 단위로 일치하는지 패키징 단계에서 검증합니다.
- 패키지 메타데이터의 시작 경로와 실제 파일 존재 여부를 확인해, 시작할 수 없는 설치 파일이 릴리스되는 것을 차단합니다.

첨부 화면과 같은 `Cannot find module ... resources\\app\\scripts\\electron\\main.cjs` 오류가 발생한 PC는 앱이 실행되지 않아 자동 업데이트를 받을 수 없습니다. 이 릴리스의 설치 파일을 직접 실행해 덮어 설치해야 합니다.
