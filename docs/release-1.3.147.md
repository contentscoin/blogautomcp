# 1.3.147 — 참조 사진의 실제 관찰 범위 일치

부분 확대 사진을 제품 전체 형상 사진으로 안내하던 경로를 수정합니다. 생성과 검수 모두 전체 실루엣이 실제로 확인된 참조만 새로운 자세의 근거로 사용하며, 기존 부분 참조는 보이는 국소 세부로 범위를 제한합니다. 원래 요청·메타데이터·픽셀은 변경하지 않습니다.

머리카락·신체·손·프레임 밖에 가려진 부분의 미관찰과 실제로 보이는 부품 누락을 구별합니다. 충분한 가시 식별 구조와 선택 옵션 확인은 계속 필요하며, 분명한 단절·다른 형상·옵션·브랜드와 해결되지 않은 식별 불확실성은 계속 차단합니다. 기존 불합격을 코드로 통과시키지 않습니다. 판매자 원본의 물체에 없는 브랜드·SKU·사이즈 표기를 새로 요구하거나 생성하지 않으며, 외부 광고를 실제 상품 인쇄로 취급하지 않습니다. 실제로 보이는 선택 상품의 컷·봉제선·목단·재질·색상·구조를 비교하고, 식별 근거가 부족하면 계속 보류합니다.

정책이 바뀌면 정확한 완료 요청·참조·출력에 결합한 검수만 새로 수행합니다. 생성 횟수 제한과 과거 실패 기록은 유지합니다. 기존 원고·정상 사진을 보존하며 승인 전 최종 검수와 별도 발행 선택 절차를 유지합니다. 실제 네 소재의 승인 준비 결과는 배포 후 별도 증거로 확인합니다.

공식 소재 보완 백업에 보존된 사진을 복원할 때도 해당 상품·슬롯·변경되지 않은 원고와 출처, 기존 파일과 검수 기록을 확인하고 현재 정책의 실제 픽셀 검수를 통과해야 합니다. 해당 사진의 원래 배정 정보만 복원하며 다른 원고·사진과 교체 과정의 파일·실패 기록은 보존합니다. 복원은 승인이 아니며 이후 최종 검수와 승인을 따로 완료해야 합니다.
