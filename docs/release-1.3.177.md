# 1.3.177

실제 PC 테스트(1.3.176)에서 쇼핑 소재 10건 중 1건만 준비완료된 원인을 코드에서 찾아 고쳤습니다. 기능이 막히던 곳, 토큰을 불필요하게 쓰던 곳, PC를 느리게 하던 곳을 함께 정리했습니다. 여행커넥트는 바뀌지 않습니다.

## 막히던 곳
- 최종 이미지 검수의 답이 형식 규칙 하나만 어겨도 그 사진이 "판정 없음"으로 끝나던 문제: 한 번 다시 묻고, 그래도 실패하면 어떤 규칙이 틀렸는지 메시지에 남깁니다.
- 검수 호출이 시간 초과·전송 오류로 실패하면 묶음 전체가 "판정 없음"이 되던 문제: 한 번 다시 호출하고, 그래도 실패하면 "검수 호출 실패"로 구분해 알립니다.
- 본문 문장을 인용한 사진 묘사 지적이 "문단 전체가 아님"으로 거절되던 문제: 한 문단 안의 정확한 문장 인용도 받습니다.
- "판정 없음"이 섞이면 승인 단계 복구가 모두 막히던 문제: 같은 사진을 한 번 다시 검수한 뒤 기존 복구(연출 사진 빼기·대표 이미지 재생성)로 이어집니다.
- 원본 사진 재배정 기록이 없을 때 `IMAGE_RESUME_REQUIRED`로 멈추던 문제: 실행된 것이 없으면 다른 복구 경로로 넘어갑니다.
- 저장된 썸네일을 문구 확인 없이 재사용해 예전 문구가 남던 문제: 현재 문구와 같거나 사용자가 직접 고친 경우에만 재사용합니다.
- 실패 이유 없이 "보완 필요"만 보이던 문제: 원고·구성 검사에서 걸린 이유를 함께 보여줍니다.

## 토큰 절감
- 발행 가능한 원고를 권고 때문에 전체 재작성하던 동작을 essential 프로필과 말투 다듬기 이후에는 건너뜁니다.
- 상품 사진 위치 찾기의 모델 호출을 사진 한 장당 최대 약 40회에서 소수로 제한했습니다.
- 판매자 사진 검수 결과를 PC에 저장해 같은 사진을 다시 검수하지 않습니다.
- 사진 썸네일 문구 대조를 현재 문구 기준으로 맞춰, 무료 대조로 끝날 수 있는 검수가 유료 검수로 넘어가지 않게 했습니다.

## PC 속도
- 소재 조회마다 모든 이미지를 최대 12번 다시 읽던 승인 상태 계산을 한 번 읽기로 줄였습니다(기존 승인 기록은 그대로 유효).
- 재작성 대상 확인이 소재마다 전체 상품을 훑던 것을 해당 상품만 보도록 바꿨습니다.
- 이미지 대기 중 전체 원고 대신 진행 상태만 확인합니다. 원격 작업 확인은 할 일이 없으면 간격을 늘립니다.

이전 검사 수준으로 되돌리려면 `.env`에 `SHOPPING_GATE_PROFILE=strict`를 설정합니다. 실제 PC에서의 동작은 이 버전에서 처음 확인합니다.
