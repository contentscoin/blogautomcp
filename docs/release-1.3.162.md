# 1.3.162

작은 제품 인쇄의 검출 영역이 일부 치우쳤을 때 OCR이 글자를 잘라 읽거나 제품 경계를 글자로 읽는 문제를 보완했습니다.

- 원본 변경 없이 고정된 최대 24픽셀 여백을 사용합니다. 기본 OCR 합의가 없을 때만 같은 영역에서 제한된 sparse-text 검사를 수행하며 기존 총 시간 제한을 유지합니다.
- 추가 여백의 글자는 원래 관찰 영역과의 기하학적 겹침으로 구분하고 제외된 원문도 기록합니다. 예상 브랜드에 맞추거나 신뢰도 85 기준을 낮추지 않습니다.
- 서로 다른 두 전처리 결과의 일치가 필요하며 동일 전처리의 모드 변경을 중복 합의로 세지 않습니다.
- OCR 실패의 세부 사유를 최종 진단에 남깁니다.

실제 이어폰 원본·후보와 이전 좌표 회귀 사례로 확인했습니다. 원고·정상 이미지는 보존하며 실제 승인 준비는 설치 후 MCP 작업의 최종 결과로 확인합니다. 초기화·발행은 수행하지 않습니다.
