# v1.3.85 — 소재 준비: 재검사 판정 일치·이미지형 상세 읽기·정보 카드

1.3.84로 소재 10개를 준비하는 중 실패 3건이 나왔다. 원인을 모두 코드에서 확인하고 고쳤다.

- **통과 원고가 "보강 거절"로 실패(에어프라이어)**
  - 원인: 저장 원고를 재검사한 결과를 이미지 상태와 합치는 단계가 fail 신호를 모두 불통과로 봤다.
    - 원 판정에서는 경고일 뿐인 "필수 흐름" 신호 하나 때문에 97점 원고가 보류됐다.
    - 그 뒤 보강 단계는 고칠 것이 없어 후보를 만들지 않았고, 이것을 "3개 후보 거절"로 처리했다.
  - 수정:
    - 이 단계에서 불통과를 만드는 신호는 구성·이미지 게이트 하나로 한정했다.
    - 차단 항목과 실패 품질 항목이 없고 점수가 기준 이상이면 재작성하지 않고 완료로 처리한다.
    - 이미 통과한 원고를 보강하라고 하면 그대로 두고 성공으로 끝낸다.
- **근거 부족으로 작성 전 중단(샤크 무선청소기)**
  - 원인: 상세페이지 판독(OCR·비전)이 세로로 긴 상세 이미지를 자른 구간만 읽었다. 보통 비율 이미지 여러 장으로 된 상세페이지는 한 장도 읽지 않았다.
  - 수정: 구간을 읽은 뒤에도 근거가 부족하면, 아직 읽지 않은 판매자 이미지를 최대 8장 더 비전으로 판독한다. 사실 채택 규칙(전사 근거 대조)은 그대로다.
  - 그래도 실패하면 오류 문구에 다음 수치를 함께 적는다: 상세 구간 수, 판매자 이미지 수, OCR 근거 수, 판독 이미지 수, 채택 줄 수, 확인 근거 수.
- **이미지 1/3장(가열식 가습기)**
  - 원인: 검증된 판매자 사진은 있지만 누끼를 딸 수 있는 사진이 없다. 그래서 연출컷도 대표 썸네일도 만들 수 없었다.
  - 수정: 이 경우 빈칸 대신 **정보 카드**를 만든다.
    - 본문 카드: 판매자 원본 사진 전체를 흰 액자에 넣고, 옆에 섹션 제목과 판매처 상세에서 확인한 사실 2~4줄을 적는다. 하단에 "판매처 상세 정보 기준 요약"을 표기한다.
    - 대표 이미지: 기존 원본 사진 썸네일 카드를 쓴다.
    - 사진은 자르거나 생성 배경에 합성하지 않는다. 연출 장면처럼 보이게 만들지 않는 기존 원칙을 지킨다.
    - 글 하나에 최대 3장만 쓴다. 섹션 본문이 언급한 사실을 먼저 싣고, 확인된 사실이 2개 미만이면 만들지 않는다.
    - 최종 이미지 감사는 액자 속 사진으로 상품 동일성을 판단한다. 카드 글자는 공지로 보지 않는다.
