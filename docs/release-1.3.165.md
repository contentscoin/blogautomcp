# 1.3.165

최종 사진 검사에서 서로 다른 촬영 면의 실제 브랜드 오타를 복구하지 못하거나, 상자 글자의 위치를 확정하지 못해 정상 기기 사진을 보류하던 연결부를 보완했습니다.

- 제품 본체의 독립 브랜드 판독과 로컬 OCR이 실제로 불일치하고, 현재 원고·상품 원본·선택한 본체·최종 외형/사진 주장/형식 검사가 모두 연결된 경우에만 **복구 전용 충돌 근거**를 남깁니다. 다른 면의 구조를 확인하지 못한 원시 판정은 그대로 보존합니다. 이 근거는 사진 승인이나 글자 일치 인증에 사용할 수 없습니다.
- 액세서리·사은품·모델명·옵션의 실제 충돌, 판독 불가, 같은 글자, 원본/원고 변경, 전송 불명 요청은 계속 차단합니다. 기존 단일 후속 생성 예산과 요청 기록 검사를 유지하고, 교체 사진도 참조 충실도 검사와 최종 검수를 받아야 합니다.
- 본문 사진의 두 대응 면은 인쇄가 없다고 관찰됐지만 상자 글자의 소속 위치만 확정하지 못한 경우에는 별도 **인쇄 미검증 경고**를 기록합니다. 정상 외형·사진 주장·형식의 현재 검수와 정확한 원본 연결이 필수이며, 실제 같은 면의 글자나 읽을 수 있는 후보 글자를 이 경고로 숨길 수 없습니다.

기존 원고·정상 사진과 과거 실패 기록을 보존합니다. 완전 초기화와 블로그 발행은 실행하지 않습니다.
