# 1.3.157

- 사진 글자 판독이 문자 체계가 섞인 잘못된 형식으로 응답한 경우, 동일 사진과 동일 지침으로 최대 한 번만 다시 요청합니다. 이전 판독 글자나 예상 브랜드를 다음 요청에 제공하지 않습니다.
- 잘못된 첫 응답과 그 해시를 보존합니다. 원문 문자 치환, 번역, 철자 보정으로 검사를 통과시키지 않습니다. 재응답도 부적합하면 중단합니다.
- 전체 판독 시간은 최대 90초입니다. 남은 시간에 기본 호출 제한을 수용할 수 있을 때만 재요청합니다. 정상적인 불확실·결함 판정, 통신 결과 미확인, 변경된 사진에는 이 재시도를 적용하지 않습니다. 동일 작업의 후속 조회로 재시도 횟수가 늘어나지 않습니다.
- 기존 원고·정상 사진 보존, 승인 전 최종 검사, 준비 전용 MCP 작업, 초기화 실행 확인 절차를 유지합니다.
- 제품·포장에 인쇄된 독립 브랜드 로고를 긴 상품명보다 우선 판독합니다. 브랜드 로고와 상품명처럼 서로 다른 종류의 식별자를 비교 대상으로 선택하지 않습니다. 일치하는 종류가 없으면 검사를 보류하며, 후보 이미지의 글자로 유리한 원본을 선택하지 않습니다.

검증: 독립 글자 판독 295개 오프라인 검사, 사진 검수 회귀 검사 및 타입 검사. 현미경 원본 두 장의 진단 호출에서 같은 브랜드 로고를 판독했으나 진단 결과는 승인 근거로 사용하지 않습니다. 실제 설치·MCP 복구 결과는 배포 후 별도로 확인합니다.
