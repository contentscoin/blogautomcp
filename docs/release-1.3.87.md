# v1.3.87 — 이미지 보충: 재계획 하한 3장, 대체 섹션 없을 때도 완화, 카드 원본 확대

1.3.86 소재 준비에서는 원고 실패가 없었다. 남은 4건은 모두 이미지 보충 단계에서 났다.

- **"전체 이미지 4/5장"에서 멈춤(베이직북14·캠핑웨건·마데카 앰플)**
  - 원인: 재계획은 전체 이미지가 5장 이상이어야 기능 섹션의 사진 요구를 내려놓았다. 1.3.86 구성 검사는 필수 슬롯이 모두 차면 3장부터 통과시키므로 두 기준이 어긋났다.
  - 수정: 재계획 하한을 3장(대표 포함)으로 맞췄다.
- **옮길 빈 섹션이 없어 바로 종료(컬크림)**
  - 원인: 재계획이 `REPLAN_NO_ALTERNATIVE_CAPACITY`에서 완화 판단 없이 끝났다.
  - 수정: 원본 탐색과 생성은 건너뛰고, 같은 3장 기준으로 완화 여부를 판단한다.
- **기능 섹션 카드 원본 부족**
  - 원인: 판매자 사진을 이미 다른 섹션에서 쓰고 있으면 카드에 쓸 원본이 없었다.
  - 수정: 이 경우 글에 이미 들어간 검증 원본으로 카드를 만든다. 카드마다 결과물이 달라 중복 검사에 걸리지 않는다.

## 검증
- `test:draft-reliability`: 4장 완화, 대체 섹션이 없을 때의 완화와 부족 사유, 2장일 때 계속 차단하는지 확인한다.
- `test:image-batch-progress`: 기존 원본으로 카드를 만드는지 확인한다.
- `verify-image-coverage-replan`: 새 하한에서도 "근거 부족" 경로를 계속 검사하도록 픽스처 이미지 수를 1장으로 줄였다.
- CI 단위 검사 전체와 관련 검사가 통과했다.
