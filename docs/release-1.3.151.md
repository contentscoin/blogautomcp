# 1.3.151

후보의 제품 인쇄가 읽히고 자신의 주 참조에서는 읽히지 않아도, 같은 선택 상품의 다른 검증 원본에 선명한 인쇄가 있으면 기존 문자 비교 경로를 사용합니다. 외부 배경 그래픽을 구분하는 위치 검사가 이 경로를 먼저 가로막던 분기 오류를 수정합니다. 원본 선택·실제 구성원 확인·독립 문자 판독과 OCR 검산을 그대로 거쳐, 일치와 실제 오타를 각각 판단합니다.

외부 그래픽 위치 검사는 읽을 수 있는 검증 원본이 없는 경우에만 기존 한 번의 질문으로 실행합니다. 그 경고를 읽는 서버도 같은 조건을 다시 검산하므로, 읽을 수 있는 원본이 추가된 상태에서 예전 외부 그래픽 경고의 해시만 다시 만들어 적용할 수 없습니다. 원본·구성원·실행 증거가 미확정이거나 부정이면 외부 경고로 우회하지 않습니다.

기존 문자 대조의 판정, 경고의 보존 방식과 실제 결함의 서명·단 한 번의 개선 예산은 바꾸지 않습니다. 이전 원고·사진·150 실행 원시 기록은 유지합니다. 배포와 새 최종 승인 여부는 설치된 버전의 실제 실행으로 별도 검증하며, 소재 준비는 발행·예약을 수행하지 않습니다.

단독 이미지의 표기 관찰은 v3 응답에서 좌표를 `left/top/width/height` 정수 객체로 반환합니다. 기존 폭 800·높이 250·면적 12%와 이미지 경계 제한은 유지하며, 폭·높이 제한을 응답 스키마에도 직접 지정합니다. 실제 원본의 안내지 전체나 긴 제목을 상한 밖으로 감싼 v2 응답이 모든 사진의 공통 실패로 이어지던 원인을 줄입니다. 완전한 짧은 식별 문구를 제한 안에서 관찰할 수 없으면 정직하게 미판독을 반환하며, 부분 단어로 잘라 통과시키지 않습니다. v1/v2 배열 응답을 v3으로 재명명하거나 과거 원시 좌표를 바꾸지 않습니다.

관찰 응답 오류는 실패한 원본 SHA와 폭·높이·면적·경계 등의 구체적 제한, 원시 응답 해시를 보존합니다. 관찰·실제 면 비교·문자 검산의 실행 오류를 분리하여 전송 또는 스키마 실패가 일반적인 결합 오류로만 보이지 않게 합니다. 이 진단 정보는 승인·사진 교체·추가 생성 권한이 아닙니다. 새 wire의 실제 호환성과 승인 준비는 151 설치 후 실제 실행에서 확인해야 합니다.

외형 비교는 선택된 제품과 그 제품의 실제 포장 상태를 구분해 관찰합니다. 두 사진에서 같은 수납가방의 창·손잡이·봉제 등 식별 구조가 확인되면, 가려진 매트 본체까지 노출하라고 요구하지 않습니다. 관련 없는 가방이나 사은품을 대신 승인하지 않으며, 실제 선택된 상품의 포장인지와 두 가지 이상의 대응 구조를 계속 확인합니다. 숨은 내용물·구성 수량·성능을 사진이 입증한다는 주장은 별도의 본문 검사에서 유지합니다. 이전 부정 응답을 긍정으로 바꾸지 않고 새 질문과 입력 범위를 별도로 기록합니다.

선택 상품의 자체 포장 또는 포장 안에 놓인 상태도 외형 검사의 명시적 대상으로 구분합니다. 양쪽 사진에서 같은 포장의 손잡이·잠금부·창·안내지 배치 등 서로 다른 실제 구조가 대응하고 선택 구성원임을 확인할 수 있으면, 가려진 매트 본체를 새로 노출하라는 조건을 추가하지 않습니다. 일반 가방의 유사성이나 출처만으로 통과하지 않으며, 다른 포장·사은품·선택 옵션 불일치·구성원 미확정은 계속 차단합니다. 숨은 내용물·수량·전체 세트를 사진이 증명한다는 원고 주장은 별도의 원고-사진 검사에서 유지합니다.
