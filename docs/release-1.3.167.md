# 1.3.167

- 복구 사진을 만들고 검수할 때 사용한 판매자 원본 연결을 최종 검수에도 전달합니다. 현재 사진·주 원본·상품 수집본과 연결된 경로만 참고하며, 현재 판매자 갤러리·수집 기록·실제 파일 바이트를 다시 확인합니다. 과거 판정이나 생성 권한을 재사용하지 않습니다.
- 여러 판매자 사진의 인쇄 판독이 충돌해 비교 원본 선택이 중단됐을 때, 마지막 사진의 판독 실패로 잘못 표시하지 않고 원본 집합 선택 단계의 문제로 기록합니다.

기존 원고와 정상 사진을 보존하며 승인 전 최종 검수를 유지합니다. 초기화·예약·발행은 실행하지 않습니다.
