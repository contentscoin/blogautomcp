# v1.3.100 — MCP와 PC의 작업 응답 안정화

PC의 상태 조회가 늦어져도 작업 임대의 연결 유지 신호를 먼저 전송합니다. 일반 폴링 자체를 소재 작업으로 세지 않아 유휴 PC가 계속 사용 중으로 표시되는 문제도 수정합니다.

- 새 Sites 서버는 접수 요청 번호로 같은 PC의 동일 작업 할당만 복구합니다. 작업이 없는 결과도 확정 기록해 늦게 도착한 같은 요청이 새 작업을 잡지 못하게 합니다. PC는 네트워크 요청 전에 접수 번호를 저장하고, 실행 시작 기록이 남은 작업을 재실행하지 않습니다.
- 구버전 Sites 서버는 기존 작업 처리를 지원합니다. 그 서버에서 접수 응답이 불명확하면 새 접수를 쌓지 않고 확인 필요로 남깁니다. 접수 응답 복구에는 PC와 Sites 서버를 함께 업데이트해야 합니다.
- 실행 완료 결과는 기존 보관함에서 재전송하며, 생성·발행 작업을 다시 실행하지 않습니다. 취소·회수된 작업은 실행 전에 확인합니다.
- 원본 상품 사진의 배정 실패가 AI 연출사진 생성 경로로 넘어가 잘못된 기능 근거 오류를 표시하던 분기를 수정합니다. 원본 수집·검수 사유를 유지하며, 이미지 요청의 실행 여부가 불명확하면 기존 차단을 유지합니다.

이 릴리스 검증에서는 실제 글 생성, 이미지 생성, 예약과 발행 요청을 실행하지 않습니다.
