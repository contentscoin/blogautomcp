# v1.3.84 — 소재 준비 첫 통과율: 채점 매칭·무브랜드 식별·썸네일 복구·이미지 하한

1.3.83 소재 10개 준비(새 상품)에서 나온 실패 5건의 원인을 고쳤다.

- **기능-사용 장면 연결 0점(골프워치)**
  - 채점기가 확인 사실을 너무 문자 그대로 비교했다.
    - "30.1g"을 "30"과 "1g"으로 쪼개 읽었다.
    - "가로·밴드 미포함" 같은 부수 단어까지 같은 문장에 있어야 인정했다.
    - "내장배터리"와 "내장 배터리"처럼 띄어쓰기만 달라도 다른 사실로 봤다.
  - 이제 소수점과 ± 기호를 유지하고, 띄어쓰기를 무시하고, 숫자 토큰 하나가 맞으면 인정한다. 숫자가 다르면 계속 불인정한다.
- **무브랜드 상품의 식별(곶감·김치)**
  - 브랜드·모델 표기가 없는 농산물·식품·선물세트는 픽셀로 브랜드를 증명할 수 없다.
  - 이런 상품은 "같은 품목, 상품명과 맞는 포장·구성, 모순 없음"이면 일치로 본다. 대표 사진 검사, 섹션 사진 검사, 최종 감사에 모두 적용한다.
  - 옵션 혼합·공지 거절은 그대로다. 모델 번호가 있는 공산품은 기존 기준을 쓴다.
- **썸네일 거절로 원고 전체 실패(곶감)**
  - 최종 감사에서 썸네일 한 장만 거절되면, 거절된 원본을 빼고 다음 검증 원본으로 썸네일을 최대 2회 다시 만든다.
  - 소재 준비에서는 그래도 안 되면 원고를 저장하고, 대표 이미지는 보충 단계에 맡긴다. 발행 모드는 그대로 멈춘다.
- **대표 사진 미확보로 원고 전체 실패(김치)**: 소재 준비에서는 썸네일 없이 원고를 저장하고 대표 이미지는 보충 단계가 채운다.
- **이미지 3/5장(침구청소기)**
  - 판매자 사진에 누끼 가능한 원본이 없어 AI 연출 대체도 불가능한 경우를 처리했다.
  - 이때는 최소 이미지 수를 3장(대표 포함)으로 두고, 이 하한을 구성 품질 검사에도 기록해 적용한다.
  - 전체 사각형 사진을 생성 배경에 합성하지 않는 원칙은 유지한다.
