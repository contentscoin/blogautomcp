# v1.3.15 — 초안 검증·이미지 재시도·MCP 안정성

- 직접 체험을 부정하거나 사용 방법을 설명하는 문장을 체험담으로 잘못 판정하는 문제 수정.
- 저장된 상품 출처로 원고를 재검사하는 기능 추가. 검증 불가능한 출처와 실제 이미지 부족은 계속 차단.
- 쇼핑·여행 참고 글의 전개 원칙을 Codex, MCP 작성 컨텍스트와 Spec-first에 반영.
- 개선 없는 반복 보강을 중단하고, 더 높은 점수라도 새로운 차단 문제가 생긴 원고는 채택하지 않음.
- 섹션 이미지 작업의 완료 결과를 재사용하고 누락 부분만 재시도. 전송 여부가 불확실한 생성 요청은 중복 전송하지 않음.
- MCP 실행 결과의 전송 복구와 큰 원고의 분할 조회 지원. 결과 전달 실패로 발행을 재실행하지 않음.
- 점수와 승인 조건, 원고 보강과 이미지 보충을 분리해 표시. 기존 원고 버튼을 '초안 확인·수정'으로 변경.

## 검증

- 생산 빌드, TypeScript, MCP 통합 13개, 저장 원고 재검사, 작성 가이드 전달 검사 통과.
- Windows 1.3.15 패키지의 시작·재시작·자체 Prisma 엔진·고정 설정·인증된 업데이트 다운로드 검증 통과. 다운로드 검사는 설치하지 않는 격리된 fixture 사용.
- 실제 모델의 원고 1건 생성 시간이나 모든 과거 원고의 승인 성공을 보장하지 않음. 출처 누락과 실제 부족 이미지는 해당 원고별 복구 필요.

기존 원고·이미지·로그인 데이터를 삭제하지 않는 업데이트입니다.
