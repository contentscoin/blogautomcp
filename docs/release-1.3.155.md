# 1.3.155

- 원고·사진 검수의 개별 Codex 호출에서 관계없는 메모리, 플러그인, 로컬 스킬 목록과 도구를 제외합니다. 공용 계정, 전역 설정과 모델 선택은 바꾸지 않습니다.
- 인쇄 검수 응답 연결 오류에 실제 실패 사유를 함께 기록합니다. 검수 기준과 승인 조건은 유지합니다.
- 기존 원고·사진은 보존하며 완전 초기화는 사용자가 직접 선택할 때만 실행됩니다. 이번 업데이트로 초기화나 발행을 실행하지 않습니다.

검증: 호출 설정 격리 및 원본 설정 보존 회귀 검사, 인쇄 검수 224개 오프라인 검증, 타입 검사, 변경 파일 린트 통과. 실제 소재 승인 결과는 별도로 확인해야 합니다.
