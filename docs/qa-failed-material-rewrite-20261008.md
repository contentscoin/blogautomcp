# 실패 소재 일괄 복구 검증

버전: PC 1.3.98, Sites MCP 1.3.12.

PC 소재 보관함과 Sites 대시보드의 실패 소재 전체 재작성·검증 버튼, MCP `materials_rewrite_failed`는 원고 작성 실패 소재를 일괄 복구한다. 정상 소재, 게시·예약 소재, 실행 중 작업 및 발행 결과가 불명확한 소재는 제외한다. 원고를 변경하기 전에 기존 패키지를 백업하며, 기존 품질·이미지·최종 승인 절차를 통과한 항목만 발행 준비 완료로 집계한다.

## 확인 결과

- 실패 대상 선정·재작성·검증·백업 검사 65개 통과.
- 소재 API 검사 19개, 기존 소재 및 예약 작성 회귀 검사 통과.
- PC 버튼과 작업 표시 검사 통과.
- Sites 전체 검사 38개 통과. 계정 소유권, 같은 출처 요청, 버전·온라인 상태, 실행 중 작업, 연결 교체 경쟁, 멱등성과 응답 유실 후 복구를 포함한다.
- PC와 Sites TypeScript 검사 통과, Sites ESLint 통과.
- Sites Vinext 프로덕션 빌드 통과.

## 독립 검토 반영

1. 이미지 복구 후 추가 원고 PATCH 보강이 발생해도 공통 백업 절차를 거치도록 수정했다. 백업 실패 시 원고 수정과 승인을 중지한다.
2. 과거 확정 발행 실패 이후 더 최근 작성 실패가 있으면 후보로 포함한다. 불확실한 발행 시도는 별도 기록으로 계속 보호한다.
3. Sites 전용 ESLint에서 발견한 초기 상태 복원 문제는 `useSyncExternalStore` 구독으로 수정했다. 요청번호·작업번호 복원과 계정 분리 검사를 추가했다.

검사는 격리된 fixture와 모의 API를 사용했다. 실제 사용자 소재 재작성, 유료 생성 및 네이버 발행은 수행하지 않았다. 배포 파일과 공개 업데이트 피드는 `out/release-1.3.98`의 검증 보고서로 별도 확인한다.
