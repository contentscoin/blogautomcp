# 1.3.145 — 완료 이미지의 안전한 복구와 원본 사진 정책 일치

이미 완료된 구버전 이미지가 새 촬영 계획과 다르다는 이유로 재검수 전에 차단되거나, 사진은 같은데 수집 기록 변경으로 복구가 막히는 경로를 보강합니다. 원래 호스트 요청·완료 결과·상품·문단·참조 픽셀이 정확히 확인되는 결과만 재검수 대상으로 사용합니다. 불확실한 요청을 다시 전송하거나 과거 기록을 덮어쓰지 않습니다.

원본 사진 선택과 최종 검사에서는 검증된 판매자 원본의 비설명형 출처 브랜드 로고를 같은 기준으로 판단합니다. 선택 상품의 검증된 원본 픽셀과 최종 사진이 정확히 같을 때만 해당 출처 로고를 허용합니다. 생성·편집 사진의 추가 로고, 상품명 헤드라인, 설명·홍보 문구, 가격·인증 배지, 배너·프레임·패널은 계속 차단합니다. 출처 일치가 실제 상품·옵션·본문 주장 검사를 면제하지 않습니다.

기존 원고·정상 이미지·과거 요청·실패 이력은 보존합니다. 부족한 단계만 처리하며 최종 원고·이미지 검수와 승인, 별도 발행 선택 절차를 유지합니다. 실제 복구 결과는 배포 후 별도로 확인하며, 이 변경을 모든 상품의 무실패 생성 보장으로 해석하지 않습니다.
