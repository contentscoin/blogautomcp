# 1.3.174

쇼핑커넥트 글이 준비 단계에서 막히는 경우를 줄였습니다. 여행커넥트는 바뀌지 않습니다.

- 쇼핑 원고는 잘못된 글만 발행을 막습니다. 상품명 누락·다른 상품군 혼입·고지 누락·본문 URL·수수료율 노출·내부 지침 유출·허위 체험·질병 치료나 부작용 단정·구조 파손이 대상입니다. 품질 점수 미달은 권고로 남고, PC 자동 작성은 권고가 있으면 한 번만 보강을 시도합니다.
- 상품 페이지의 내장 데이터에서 상품명·가격·이미지·속성·옵션을 먼저 읽습니다. 텍스트 근거가 적어도 작성을 중단하지 않고, 제공되지 않은 수치·규격을 만들지 않도록 지시합니다.
- AI 연출 사진을 만들지 못해도 글이 준비됩니다. 빈 자리는 서로 다른 판매자 실사진으로 채우며(본문 원본 최대 4장), 붙일 사진이 없으면 원본 1장으로 준비합니다. 로그인 만료·엔진 연결 실패·취소는 이전처럼 실패로 알립니다.
- 쇼핑 글 소제목 앞에 내용에 맞는 이모지 1개를 붙이고, 상황 → 결론 → 근거 → 한계 → 맞는 사람 순서의 구성 지시를 추가했습니다.
- 상품 동기화가 끝나면 가져온 개수의 이유를 알려줍니다. 브랜드 검색어에 맞는 상품이 적으면 탐색 범위를 넓혀 다시 확인합니다.
- ChatGPT 플러그인 안내문 맨 앞에 기본 흐름(상태 확인 → 상품 가져오기 → 소재 준비 → 확인 → 발행)을 두었습니다.

이전 검사 수준으로 되돌리려면 `.env`에 `SHOPPING_GATE_PROFILE=strict`를 설정합니다. 자세한 내용은 `docs/shopping-essential-gate.md`에 있습니다.

실제 PC·네이버 환경에서의 동작은 이 버전에서 처음 확인합니다.
