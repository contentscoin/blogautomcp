# v1.3.77 — 계정별 쇼핑 연결 및 이미지 복구

- 쇼핑 목록과 자동등록이 현재 로그인 세션의 카테고리 주소를 함께 탐색한다. 특정 계정의 고정 공간 ID를 기본값으로 사용하지 않는다. 소개 페이지의 실제 SSO 링크를 따라가며, 로그인 필요와 공간 권한 오류를 구분한다.
- 이미지 접수는 해당 프롬프트와 일치하는 새로운 사용자 메시지로 확인한다. 첨부파일 이름이 있는 메시지와 일반/Custom GPT 대화 복구를 지원한다.
- 전송 전 일시 오류만 기존 준비 시간 한도 안에서 한 번 재시도한다. 불명확한 전송, 사용자 종료, 인증 문제는 자동 재전송하지 않는다. 원인 코드와 실패 단계를 저장한다.
- 제품 원본/기능 근거/이미지 품질 기준과 예약 발행 핵심 로직은 변경하지 않았다.
- 15개 회귀 검사 묶음을 CI와 설치본 빌드 앞단에 연결했다. 로컬에서 검증한 React DOM 타입 버전을 고정해 깨끗한 설치 환경의 peer 의존성 충돌을 예방한다.

## 검증과 범위

- 이전 턴에서 최종 소스의 타입 검사, 프로덕션 빌드, 회귀 검사 15개 묶음 통과. 이미지 배치 45개와 픽셀 검수 37개 시나리오 포함.
- 다른 PC의 실제 계정 로그인·이미지 생성·예약 성공은 오프라인 검증과 별개다. 로컬 저장 세션은 네이버 로그인 화면에 머물렀으므로 성공으로 보고하지 않는다.
- 이번 릴리스는 Windows 설치 파일 및 중앙 업데이트 피드 게시 대상이다. 공개 Sites 애플리케이션 소스 변경은 없다.
- v1.3.77 격리 설치본 실행 검사 통과: 화면 HTTP 200, 고정 설정, 자체 Prisma 엔진, 인증된 업데이트 메타데이터/파일 다운로드, 수동 확인과 프로그램 재실행, 토큰 비노출. 감지된 1.3.78은 테스트용 fixture이며 실제 설치·게시하지 않았다.
- 설치본의 쇼핑 조회/등록 및 이미지 접수/복구 핵심 파일 5개의 SHA-256이 검증된 작업 소스와 일치했다.
- 기존 CI의 CommonJS 테스트 파일에만 CommonJS/VM용 lint 설정을 적용했다. 앱 런타임 및 품질 임계값은 변경하지 않았다.
