# 1.3.146 — 부족한 사진 단계의 연속 복구

완료 사진의 검수에서 실제 제품 불일치가 확인되면, 현재 상품·원고·슬롯에 결합된 확정 거절 근거로 기존 1회 개선 절차를 이어갑니다. 불확실한 완료나 검수 오류를 재생성 근거로 쓰지 않습니다.

기존 판매자 원본이 현재 본문의 외형 설명과 맞지 않을 때는 실제 거절된 원본 슬롯만 같은 상품의 검증된 원본으로 복구합니다. 기존 원고·정상 이미지·원래 파일·거절 이력은 보존하고, 생성 이미지로 원본을 대체하지 않습니다. 대체 사진도 출처·본문 의미 검사와 최종 승인 검사를 통과해야 합니다.

복구 후에도 발행·예약은 별도로 선택합니다. 실제 소재 복구 결과는 배포 후 검증 기록으로 확인하며 무실패 생성을 보장하지 않습니다.

사진 검수에서는 관찰 거리 때문에 읽을 수 없는 작은 표기와 실제 인쇄 불일치를 구분합니다. 같은 위치의 작은 표기가 존재하고 식별 가능한 제품 형상·옵션과 추가 참조에 모순이 없을 때만 관찰 한계로 기록합니다. 선명한 빈 표면·다른 문자·불확실한 형상이나 옵션, 본문의 근거 없는 판독 주장은 계속 차단합니다. 과거 불합격을 자동 통과시키지 않으며 현재 정책으로 실제 사진을 다시 검수합니다.
