# v1.3.86 — 소재 준비: 정보 카드 승인·권고 신호·디지털 사실·여행 일정·섹션 분할

1.3.85로 여행 10개와 쇼핑 10개를 준비했다. 여행은 6개가 완료됐지만 4개가 실패했고, 쇼핑은 10개 전부 확인 필요로 끝났다. 원인 8가지를 고쳤다.

- **정보 카드가 승인 단계에서 막힘(한우·LA갈비·마데카·베이직북)**
  - 원인: 승인 검사가 원본 사진 전체를 담은 카드를 "생성 배경 위 합성"으로 보고 차단했다.
  - 수정: 카드는 생성 배경이 없는 단색 카드라서 이 검사에서 제외했다. 생성 배경 합성은 계속 차단한다.
- **"제품정체-기능원리-사용법-장단점-결론 흐름" 하나로 승인 불가**
  - 원인: 원래 권고 항목인데 신호 값이 fail이라 승인 쪽이 불통과로 읽었다.
  - 수정: 총점이 기준 이상이면 이 신호는 경고로 둔다. 섹션 수와 해시태그 신호도 차단 기준과 맞췄다.
- **디지털·가전 상세의 근거 탈락(삼탠바이미)**
  - 원인: 이미지에서 읽은 "화면 크기: 27형", "주사율: 60Hz" 같은 줄을 사실 필터가 버렸다.
  - 수정: 필터가 화면·해상도·프로세서·메모리 같은 라벨과 인치·형·Hz·GB 같은 단위를 인식한다.
- **구성 검사만 남아 멈춤(헥사 타프)**
  - 원인: 원고 검사는 분량·섹션 80%까지 통과시키는데, 구성 검사는 100%를 요구했다.
  - 수정: 구성 검사도 80% 미만일 때만 차단한다. 필수 섹션 이미지가 모두 찼으면 전체 이미지는 3장부터 통과하고, 5장에 못 미치는 만큼은 경고로 남긴다. 그래도 멈추면 실제 차단 사유를 메시지에 적는다.
- **기능 섹션 사진 없음(한우 정육담다·올리브오일)**
  - 원인: 기능 섹션과 맞는 판매자 사진이 없으면 대체 수단이 없었다.
  - 수정: 섹션 본문이 말하는 확인 사실이 들어간 정보 카드로 채운다. 사실이 섹션과 맞지 않으면 만들지 않는다.
- **여행 일정 근거 부족(동경 4일)**
  - 원인: 호텔·자유일정 상품은 추천 관광지 목록이 비어 있었다. 또 상세 이미지 판독이 근거 검사보다 늦게 실행됐다.
  - 수정:
    - 일정표의 실제 방문지로 핵심 방문지를 채운다. 공항·호텔·식사·자유시간은 제외한다.
    - 근거 검사 전에 상세 이미지를 읽고, "N일차" 줄로 비어 있는 일차만 채운다.
- **섹션이 한 덩어리로 옴(후쿠오카·타이페이)**
  - 원인: 모델이 섹션을 문자열 하나에 몰아서 줬다.
  - 수정: 분할기가 다음 형태의 제목을 인식해 나눈다: `## 제목` 바로 아래 본문, `**제목**`, "N일차 …", ■ 같은 기호 제목. 문장으로 끝나는 줄은 제목으로 보지 않는다.
- **빠진 방문지 보강 실패(보라카이)**
  - 원인: 검사 메모에 방문지 개수만 있고, 어떤 방문지가 빠졌는지는 없었다.
  - 수정: 빠진 방문지 이름을 메모에 적어 보강 지시에 전달한다.

## 검증

- `test:draft-reliability`: 카드 승인 예외, 권고 신호, 디지털 사실, 호텔형 여행 일정·판독 병합, 제목 분할 4종, 빠진 방문지 메모를 추가했다.
- `test:image-batch-progress`: 기능 섹션 카드 대체, 사실 불일치와 원본 전용 모드에서는 기존 오류가 유지되는지 추가했다.
- CI 단위 검사 전체와 관련 검사(재계획, 이미지 복구, 최종·제안 감사, 품질 수렴, 여행 계약, 원고 구조, 콘텐츠 준비도)가 통과했다.
