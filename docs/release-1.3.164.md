# 1.3.164

제품 인쇄 판독기가 같은 글자를 반복해서 혼합 문자로 반환해 소재 복구가 중단되는 경우를 보완했습니다.

- 확실히 수신한 혼합 문자 형식 오류가 두 번 나온 경우에만, 같은 사진의 원래 관찰 영역에서 로컬 OCR을 최대 12초 수행합니다. AI 호출 수와 전체 시간 제한은 유지합니다. 응답 불명·유효한 판독 불가·임의의 형식 오류에는 적용하지 않습니다.
- 예상 브랜드를 전달하거나 문자를 바꾸지 않습니다. OCR의 서로 다른 전처리 두 개가 신뢰도 85 이상으로 같은 글자를 읽어야 합니다. 원래 모델 응답과 OCR 원문·파일·영역·실행 파일·설정 해시를 보존합니다.
- 로컬 OCR 결과는 모델 응답과 구분되는 별도 봉투에 저장합니다. 출처 기록 누락·변조·시험용 주입 결과는 실제 검수 권한으로 사용할 수 없습니다. 이후 제품 대응·독립 글자 비교·최종 검수는 계속 수행합니다.

실제 실패 사진과 좌표를 사용한 복구·변조 방지·중복 호출 제한 검사가 통과했습니다. 원고·정상 이미지는 보존하며, 초기화·발행은 수행하지 않습니다.
