# 1.3.153

소재 보완 중 반복된 검수 요청 오류를 수정합니다. 고정된 인쇄 좌표를 응답 스키마의 배열 열거값으로 보내던 경로를 지원되는 정수 배열 형식으로 변경합니다. 반환된 좌표가 원래 관찰 좌표와 정확히 같은지는 서버에서 계속 검사합니다. 응답 형식을 검사하는 회귀 테스트와 실제 엔진의 요청 확인을 함께 사용합니다.

포장 라벨의 위치를 비교하는 영역과 글자를 읽는 작은 영역을 구분합니다. 라벨 전체를 단어 하나용 크기 제한으로 거절하던 오류를 수정하며, 실제 글자 판독과 오타·누락 증거의 크기 제한은 유지합니다. 외형·옵션·사진 설명·형식을 통과하고 정확한 인쇄 판독을 주장하지 않는 사진에서만, 여러 문구 중 판독 대상을 하나로 특정할 수 없는 관찰을 별도의 미검증 경고로 남깁니다. 이 경고는 글자 정확성 인증이나 새 사진 생성 권한이 아닙니다.

글자 관찰은 서로 혼동하기 쉬운 문자군이 한 단어 안에 섞이지 않도록 생성 규격과 파서에서 함께 확인합니다. 원시 글자를 다른 문자로 바꾸거나 공백을 지워 통과시키지 않습니다. 비교할 판매자 원본은 후보 사진의 글자나 예상 브랜드명을 보지 않고 독립적인 원본 관찰에서 선택합니다. 실제 오타·노출된 인쇄 누락·다른 제품·변경된 근거는 계속 차단합니다.

여러 원본에서 서로 다른 글자가 관찰되면 같은 식별 역할과 원시 글자가 정확히 일치하는 서로 다른 사진의 과반 관찰을 먼저 사용하고, 그 안에서 글자 영역이 큰 원본을 고릅니다. 대소문자·공백을 바꾸어 표를 합치거나 같은 사진을 중복 계산하지 않습니다. 유효 원본이 하나뿐인 경우 기존 독립 검산은 유지하며, 대립하는 단독 관찰·동률·서로 다른 식별 역할은 철자 충돌의 증거가 아니므로 보류합니다. 이 보류는 새 사진 생성 권한을 만들지 않습니다.

사진 주장 판정과 인용 근거를 하나의 응답 묶음으로 생성합니다. 원문 문단 전체와 위치·해시를 고정하고, 본문이나 제목의 성능·결과 주장은 같은 원문 인용 문단 단위에 사진이 그 사실을 보여주거나 입증한다는 연결이 있을 때 사진 근거 검사에 포함합니다. 사진 옆에 있는 판매자 근거 기반 기능 설명만으로 사진이 성능을 입증해야 한다고 해석하지 않습니다. 실제 외형·수량·전체 구성 주장, 썸네일 안의 주장과 원고의 사실 검사는 유지합니다.

기존 원고·정상 사진과 실패 당시 원시 응답은 보존합니다. 과거 부정 응답을 수정하거나 새 규격으로 바꾸어 승인하지 않습니다. 수정본에서 필요한 단계와 최종 승인을 확인하며, 소재 복구는 발행·예약을 실행하지 않습니다.
