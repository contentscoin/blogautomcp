# v1.3.82 — 소재 미리작성 이미지·보강 실패 수정

1.3.81 소재 작성에서 남은 실패 5건의 원인을 고쳤다.

- **판매자 이미지 디코딩 실패(INVALID_IMAGE, 꽃게)**
  - 판매페이지의 움직이는 GIF/WebP 배너와 디코더 경고가 있는 JPEG를 최종 감사가 "정지 이미지로 완전히 읽을 수 없음"으로 막았다.
  - 이제 판매자 이미지를 모을 때 첫 프레임 PNG로 정리해 쓰고, 아예 읽을 수 없는 파일은 후보에서 뺀다.
  - 제안 이미지 한 장의 디코딩·누락·세로 비율 문제는 그 제안만 탈락시키고, 이미지 재배치 전체는 계속한다.
- **검증 이미지 부족(IMAGE_SOURCE_BINDING_REQUIRED, 청소기·보풀제거기·선크림)**
  - 기능 근거 섹션 2곳은 판매자 원본 중 그 기능을 직접 보여주는 사진이 필요하다. 판매자 사진이 적으면 대체 섹션을 찾지 못해 막혔다.
  - 이제 원본 검토로도 부족하면, 그 이미지 몫을 선택 섹션 중 생활 장면 섹션으로 옮긴다. 그 자리는 실제 상품 누끼를 생성 배경에 합성한 AI 연출컷으로 채운다.
  - 기능 섹션의 글과 이미지 의도는 바꾸지 않는다. 연출컷을 기능 증거로 표시하지 않는다.
- **내부 문구 유출로 보강 거절(QUALITY_REPAIR_REJECTED, 선크림)**
  - 내부 지침 문구가 든 문장은 규칙으로 바로 지운다. 새 원고와 저장 원고 보강 후보 모두에 적용한다.
  - 품질 항목 절반 이상이 실패한 저장 원고는 문단 몇 개가 아니라 본문 전체를 보강 대상으로 둔다.
