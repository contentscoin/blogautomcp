# v1.3.103 — 버튼 동작과 설정 저장 안정성 개선

실행 중인 작업을 끊을 수 있던 트레이 재시작, 설정 저장 실패 후 일부 설정이 적용되는 문제, 관리자 승인·거절 버튼의 동시 처리 문제를 수정합니다. 소재 생성·키워드·히스토리 화면도 실패 원인을 표시하고 다시 시도할 수 있게 합니다.

- 트레이와 화면의 재시작에 작업 상태 보호를 적용합니다. 상태를 확인하지 못하거나 작업이 진행 중이면 재시작을 보류하고, 준비 중에는 새 자동화 작업을 받지 않습니다. 기존 작업의 완료 응답과 하트비트는 유지합니다.
- 설정 전체를 검증한 뒤 파일을 원자적으로 저장하고 실행 환경에 반영합니다. 검증 또는 저장에 실패하면 기존 설정을 유지합니다.
- Sites 관리자 버튼은 사용자별로 중복 요청을 막고 서버의 확인된 응답만 반영합니다. 다른 사용자 작업의 완료가 진행 중인 행을 다시 활성화하지 않습니다.
- Enter와 빠른 반복 클릭으로 소재 생성이 중복 실행되지 않습니다. 생성 응답의 필수 필드를 검증하고, 로컬 후보로 대체한 경우 근거 확인 안내를 표시합니다.
- 키워드 조회·품질 분석·히스토리 조회에 실패 원인과 재시도 동작을 제공합니다. 실패한 조회의 이전 결과를 최신 결과로 표시하지 않습니다.
- 키워드와 소재 복사는 클립보드 쓰기가 완료된 뒤 성공을 표시하고, 거부되면 직접 복사 안내를 표시합니다.

회귀 검증은 실제 컴포넌트·라우트와 격리된 모의 응답으로 수행합니다. 실제 네이버 로그인, 유료 생성, 글 발행·예약, 사용자 승인·거절, 설치 프로그램 실행은 릴리스 검증에 포함하지 않습니다.

검증: 신규 버튼·설정 회귀 36개와 관리자 동시 처리 회귀 4개, 전체 Sites 회귀 100개, 기존 작업 안전성 64개 통과. 자동 업데이트·고정 원고 설정 검증과 TypeScript도 통과했습니다. 재시작·설정 및 관리자 변경은 독립 검토를 통과했습니다. 린트 오류는 없으며 기존 미사용 변수 경고는 남아 있습니다.
