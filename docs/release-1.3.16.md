# v1.3.16 — 여행 원고 문맥 검증 개선

- 여행지 별칭·복합 지명과 같은 문단의 후속 설명을 인식합니다. 다른 문단의 무관한 근거는 합산하지 않습니다.
- 총점 미달과 필수 품질 조건 미달을 구분하고, 이미지 반영 후에도 올바른 보류 사유를 유지합니다.
- 원고의 다양한 구성, 일정 순서, 확정 불포함 및 숙박 미확정 조건을 작성 지침에 보강했습니다.
- 본문에 섞인 제휴 고지를 분리할 때 본문을 보존합니다.
- 정보형 여행 썸네일 문구와 섹션별 이미지 구도 지침을 개선하고 이미지별 처리 시간을 기록합니다.

기존 원고·이미지·계정 데이터는 삭제하지 않습니다. 기존 원고는 업데이트 후 다시 검사할 수 있으며 자동 승인·발행하지 않습니다.
이미지 생성 속도 개선이나 모든 원고의 승인 성공을 보장하지 않습니다. 실제 생성 품질·속도는 별도 측정이 필요합니다.
