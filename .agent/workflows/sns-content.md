# /sns-content 워크플로우

이 워크플로우는 **MIR** 에이전트를 호출하여 여러 SNS 플랫폼용 콘텐츠를 한 번에 생성합니다.

## 지원 플랫폼

- 📸 인스타그램 (피드, 릴스, 스토리)
- 🧵 스레드
- 📝 네이버 블로그 (간략 버전)

## 워크플로우 단계

1. **주제 입력** - 캠페인/제품/서비스 정보
2. **플랫폼별 최적화** - 각 플랫폼 특성에 맞게 변환
3. **콘텐츠 생성** - 캡션, 해시태그, 이미지 가이드
4. **게시 일정 제안** - 최적 게시 시간 추천

## 명령어

```
/sns-content [주제/캠페인]
```

## 예시

```
/sns-content 신제품 출시 - AI 헤어스타일 변환 앱
```

**MIR 응답:**
```markdown
# SNS 콘텐츠 패키지: AI 헤어스타일 앱

## 📸 인스타그램 피드
**캡션:**
"상상만 하던 헤어스타일, 이제 AI로 미리보기 ✨

💇‍♀️ 사진 한 장이면 OK
🎨 100가지 스타일 무료 체험
⚡ 5초만에 결과 확인

프로필 링크에서 지금 바로 체험해보세요!
👆 @hairsalon_ai

#AI헤어스타일 #헤어스타일추천 #버추얼헤어"

**이미지 가이드:**
- Before/After 비교 (캐러셀 추천)
- 밝은 배경, 얼굴 중심

---

## 🧵 스레드
"AI가 당신의 다음 헤어스타일을 찾아드립니다 💇‍♀️

1️⃣ 셀카 한 장 업로드
2️⃣ 원하는 스타일 선택
3️⃣ 5초 만에 결과 확인

미용실 가기 전 필수! 
링크는 인스타 프로필에 👆"

---

## 📝 네이버 블로그 (요약)
"AI 헤어스타일 변환 앱 체험 후기 - 미용실 가기 전 필수템!"
- 키워드: AI헤어, 헤어스타일시뮬레이션
```

## 관련 에이전트

- **MIR** - 멀티플랫폼 콘텐츠 제작
