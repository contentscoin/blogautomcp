# /naver-blog 워크플로우

이 워크플로우는 **MIR** 에이전트를 호출하여 네이버 블로그 콘텐츠를 생성합니다.

## 워크플로우 단계

1. **주제 분석** - 타겟 키워드 및 검색 의도 파악
2. **경쟁 분석** - 상위 노출 콘텐츠 분석
3. **콘텐츠 구조화** - SEO 최적화된 포스트 구조 설계
4. **콘텐츠 작성** - 본문 작성 (네이버 스마트에디터 형식)
5. **이미지 가이드** - 필요한 이미지 및 배치 안내

## 명령어

```
/naver-blog [키워드 또는 주제]
```

## 예시

```
/naver-blog 서울 맛집 추천
```

**MIR 응답:**
```markdown
# 네이버 블로그 포스트: 서울 맛집 추천

## SEO 분석
- 메인 키워드: 서울 맛집
- 연관 키워드: 서울 데이트 코스, 강남 맛집, 혼밥 맛집
- 검색량: 높음 | 경쟁도: 높음

## 제목 후보
1. 서울 맛집 베스트 10 | 현지인 추천 숨은 명소
2. [2026] 서울 맛집 총정리 - 강남부터 홍대까지
3. 서울 데이트 맛집 추천 ❤️ 분위기 좋은 레스토랑

## 콘텐츠 구조
1. 도입부 (100-150자)
2. 맛집 #1 소개 (300자 + 이미지 2장)
3. 맛집 #2 소개 ...
4. 마무리 + CTA

## 해시태그
#서울맛집 #데이트코스 #강남맛집 #홍대맛집 #서울여행
```

## 관련 에이전트

- **MIR** - 콘텐츠 전략 및 작성
- **Atlas** - 콘텐츠 자동화 시스템 설계
